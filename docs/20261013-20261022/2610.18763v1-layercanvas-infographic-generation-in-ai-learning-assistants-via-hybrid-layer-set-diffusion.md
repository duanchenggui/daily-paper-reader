## 摘要
在线学习平台正日益部署AI助手，以提供个性化、按需的辅导。这些助手可利用信息图来传达复杂信息并改善学习体验。然而，自动化生成有效的信息图仍是一项具有挑战性的任务，需要将视觉丰富性与精确排版、结构化布局以及持续可编辑性相结合。现有表示方法仅部分满足这些目标：可缩放矢量图形（SVG）表示保留了几何形状、层次结构和文本，但美学灵活性有限；而栅格扩散模型通过将内容和布局扁平化为单张图像来产生更丰富的外观。以栅格化SVG为条件对扩散模型进行条件化并不能解决这一冲突，因为栅格保留了近似位置，却丢弃了元素归属、遮挡关系以及修改和重组结果所需的结构。我们提出LayerCanvas，一种混合方法，保留SVG作为语义、结构和排版程序，同时利用扩散对非文本内容进行美学化。LayerCanvas并非生成单张扁平化栅格，而是将SVG元素划分为按z序排列的互不重叠元素集合，并通过相互通信的并行RGB生成流进行处理。所得图层可独立编辑并可确定性重组，而文本则由保留的矢量元数据渲染。我们的方法将丰富的视觉合成与精确排版和局部编辑相结合。LayerCanvas在显著提高文本保真度方面优于最先进的栅格图像生成器，同时实现最高的整体美学质量。我们进一步展示了非破坏性内容编辑、本地化、素材复用和动画。

## Abstract
Online learning platforms are increasingly deploying AI assistants to provide personalized, on-demand tutoring. These can leverage infographics to communicate complex information and improve the learning experience. However, automating effective infographic generation remains a challenging task, requiring a combination of visual richness with precise typography, structured layouts, and continued editability. Existing representation methods satisfy these goals only in part: Scalable Vector Graphics (SVG) representations preserve geometry, hierarchy, and text but provide limited aesthetic flexibility, while raster diffusion models produce richer appearances by flattening content and layout into a single image. Conditioning a diffusion model on a rasterized SVG does not resolve this conflict because the raster preserves approximate placement but discards element ownership, occlusion relationships, and the structure needed to modify and recompose the result. We introduce LayerCanvas, a hybrid approach that retains SVG as the semantic, structural, and typographic program while using diffusion to aestheticize non-text content. Rather than generating one flattened raster, LayerCanvas partitions SVG elements into z-ordered sets of mutually non-overlapping elements and processes them through communicating parallel RGB generation streams. The resulting layers are independently editable and deterministically recomposed, while text is rendered from preserved vector metadata. Our approach combines rich visual synthesis with accurate typography and localized editing. LayerCanvas substantially improves text fidelity over state-of-the-art raster image generators while achieving the highest overall aesthetic quality. We further demonstrate non-destructive content editing, localization, asset reuse, and animation.

# LayerCanvas 论文结构化总结

## 1. 核心问题与研究动机

- **应用背景**：在线学习平台大量部署 AI 助手做个性化辅导，信息图（文字+图示+插图）能提升理解与记忆，因此需要**自动生成**教学信息图，且必须能随内容/语言/屏幕尺寸不断修改。
- **双重需求冲突**：信息图既要“精确排版、结构清晰、可编辑”，又要“视觉丰富”。
  - **SVG 路线**：几何、分组、文本、绘制顺序全部显式，天然可编辑，但自动生成的 SVG 视觉僵硬、手工美化成本高、难扩展。
  - **栅格扩散路线**（SDXL、DiT/MMDiT 类）：美学先验强，但把内容与布局压平成单张图，文字渲染不可靠（密集文本易乱码），局部修改困难。
- **关键判断**：把 SVG 栅格化后作为扩散条件（ControlNet/T2I-Adapter 式）**并不能解决矛盾**——栅格只保留粗略位置，丢弃了元素归属（ownership）、遮挡关系与可重组结构，事后也无法从像素恢复。
- **论文主张**：应在整个合成过程中**始终保留构图单元**，而不是生成后再分割。于是提出 **LayerCanvas**：SVG 作为语义/结构/排版“程序”，扩散只负责非文本内容的“美学化”，文本完全由矢量元数据渲染。

## 2. 方法论

### 2.1 问题形式化

- 场景表示为 **S = (E, T, H, z, M)**：非文本元素集 E、文本与排版 T、父子层级 H、绘制序 z、以及元素类型 τ、归一化包围盒 b、渲染器导出的掩码 M。
- 每个元素同时保留**全掩码（amodal）A_i** 与**可见掩码 V_i**；二者之差 H_i=(A_i−V_i)⁺ 即被遮挡区域，为“删除/平移/z 序调整后露出的内容”提供训练目标。
- 输出为**混合产物**：A = (S, {L̂_g}, R)，最终图 = 按 z 序 alpha 合成各 RGB 层后，再叠加矢量文本层 R_text(T)。

### 2.2 有序非重叠图层集合（核心表示）

- 不为每个 SVG 元素开一条扩散路径（太贵），而是把**互不重叠**的元素打包进同一层：
  - 组内约束：A_i ⊙ A_j = 0；
  - 组间约束：若 A_i ⊙ A_j ≠ 0 且 z_i < z_j，则 g(i) < g(j)（前者必须更靠前生成）。
- 贪心构造：按 (z_i, i) 升序处理，g(i) = 1（若无已处理的遮挡者），否则 = 1 + max{ g(j) : j 已处理且与 i 重叠 }。
- 因此**路径数取决于遮挡深度而非元素个数**；组掩码取并集，最终用预乘 alpha 从后往前合成。所有组**并行去噪**，绘制序只决定合成顺序，不决定生成顺序；单个层之后可平移/删除/重排而无需重采样其他层。

### 2.3 协同的多层生成

- **共享+私有噪声**：ε_g = √ρ·ε_sh + √(1−ρ)·ε_pr，ρ~U(0.5,1)，所有层共用同一时间步 t，保证“同一噪声水平下通信”，共享成分统一整体色调，私有成分保留层内细节。
- **流匹配训练**：线性路径 x_t = (1−t)ε + t·x₁，速度目标 u_g = x₁,g − ε_g，主损失为掩码加权 MSE（忽略批处理用的空槽位）。
- **冻结 MMDiT 主干 + 可训练适配器**（借鉴 ControlNet / T2I-Adapter）：
  - **层身份编码**：q_g = LN(s_g) + E_z[g] + E_τ[τ_g]，即 VAE 控制特征 + 绘制序嵌入 + 主元素类型嵌入，经零初始化投影注入主干输入端与若干深度，训练初期不改变预训练行为。
- **层集通信块（LayerSetCommunicationBlock）**：
  - 每层压缩为一个摘要 h_g（全图/隐藏区统计、可见区与边界带均值、2×2 池化、类型、包围盒、绘制序、时间步、局部文本上下文、全局特征）；
  - 注意力打分 = 查询-键相似度 + **SVG 关系偏置**（E_gh 含 4 类有向关系：后→前遮挡、前→后、父→子、子→父），softmax 后加权聚合其他层摘要；因为关系有方向，被遮挡背景可收到与前景不同的消息。
- **双路径回注**：
  - 风格路径 r_sty：预测 2×2 粗网格并上采样，做**全层平滑**的外观修正（统一配色/光照）；
  - 边界路径 r_bnd：与当前特征结合后乘以窄带掩码 B_g，只在**轮廓与层间接触处**生效；
  - 二者由可学习门控 γ 加权（初始偏置 −2.0 / −2.5，初始强度约 0.12 / 0.076），输出层零初始化。
- **总损失**：L = λ_layer·L_layer + λ_comp·L_comp + λ_hid·L_hid + λ_bnd·L_bnd。其中合成损失按绘制序对“单步干净估计 x̂₁,g”做掩码合成后与干净合成结果比对；辅助损失直接在打包潜表示上计算，**无需 VAE 解码整图**。
- **精确排版**：所有文本节点从扩散目标中移除，提示词要求留白；生成后把透明矢量文本层叠在无文本合成图之上。因此改文案、改字体、换语言只需重渲染矢量，**不触发扩散**。

### 2.4 训练数据自动构建（多智能体流水线）

- **Stage A（LLM 设计智能体，Claude Opus 4.8）**：在 1536×1024 画布上生成可编辑 SVG，必须标注 ≥1 个 `<g data-role="editable-visual" data-edit-prompt=...>` 可编辑视觉组；14 种版式原型轮换；禁止把屏幕/仪表盘/表格等含文本的平面物体标为可编辑；带“渲染—自检—修订”闭环。
- **Stage B（结构抽取）**：“rawify” 去掉颜色/字体/渐变/纹理、文本置为中性字体，得到只含几何与绘制序的结构输入；另渲染无文本布局；序列化文本 run、插图、调色板等结构化元数据。
- **Stage C（美学化）**：用 Qwen-Image-Edit 对每个可编辑裁剪区单独重绘为插图（白底），支持 6 种风格（写实/扁平/软 3D/卡通/水彩/等距）。
- **Stage D（抠图与按 z 序合成）**：rembg/u2net 抠图 → 取最大连通域并羽化 → 贴合占位框 → 按原 z 序回填，最后叠加矢量文本。
- 另有**风格增强与稠密复用**：复用已验证的结构层，只重跑 Stage C/D 生成多风格变体；并用旧插图构造更高遮挡深度的布局。
