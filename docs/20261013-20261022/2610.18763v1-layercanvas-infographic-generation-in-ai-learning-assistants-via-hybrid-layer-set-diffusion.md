## 摘要
在线学习平台正越来越多地部署 AI 助手，以提供个性化、按需的辅导。这些助手可以利用信息图传达复杂信息并改善学习体验。然而，自动化生成有效的信息图仍是一项具有挑战性的任务，需要将丰富的视觉效果与精确的排版、结构化布局以及持续可编辑性结合起来。现有表示方法只能部分满足这些目标：可缩放矢量图形（SVG）表示保留了几何结构、层次关系和文本，但美学灵活性有限；而栅格扩散模型通过将内容和布局扁平化为单张图像，能够产生更丰富的外观。以栅格化 SVG 作为扩散模型的条件并不能解决这一冲突，因为栅格仅保留近似的位置，却丢弃了元素归属、遮挡关系以及修改和重新组合结果所需的结构。我们提出 LayerCanvas，这是一种混合方法，它将 SVG 保留为语义、结构和排版程序，同时利用扩散模型对非文本内容进行美学化处理。LayerCanvas 不生成单张扁平化栅格，而是将 SVG 元素划分为按 z 序排列的互不重叠元素集合，并通过相互通信的并行 RGB 生成流进行处理。所得图层可独立编辑并可确定性地重新组合，而文本则由保留的矢量元数据渲染。我们的方法将丰富的视觉合成与准确的排版和局部编辑相结合。LayerCanvas 在文本保真度上显著优于最先进的栅格图像生成器，同时实现了最高的整体美学质量。我们进一步展示了非破坏性内容编辑、本地化、资产复用和动画。

## Abstract
Online learning platforms are increasingly deploying AI assistants to provide personalized, on-demand tutoring. These can leverage infographics to communicate complex information and improve the learning experience. However, automating effective infographic generation remains a challenging task, requiring a combination of visual richness with precise typography, structured layouts, and continued editability. Existing representation methods satisfy these goals only in part: Scalable Vector Graphics (SVG) representations preserve geometry, hierarchy, and text but provide limited aesthetic flexibility, while raster diffusion models produce richer appearances by flattening content and layout into a single image. Conditioning a diffusion model on a rasterized SVG does not resolve this conflict because the raster preserves approximate placement but discards element ownership, occlusion relationships, and the structure needed to modify and recompose the result. We introduce LayerCanvas, a hybrid approach that retains SVG as the semantic, structural, and typographic program while using diffusion to aestheticize non-text content. Rather than generating one flattened raster, LayerCanvas partitions SVG elements into z-ordered sets of mutually non-overlapping elements and processes them through communicating parallel RGB generation streams. The resulting layers are independently editable and deterministically recomposed, while text is rendered from preserved vector metadata. Our approach combines rich visual synthesis with accurate typography and localized editing. LayerCanvas substantially improves text fidelity over state-of-the-art raster image generators while achieving the highest overall aesthetic quality. We further demonstrate non-destructive content editing, localization, asset reuse, and animation.

- **应用背景**：在线学习平台正在部署 AI 助教，信息图（文字 + 图示 + 插画）是提升理解与记忆的重要载体；平台还要求内容能快速改写、翻译、适配不同屏幕。
- **核心矛盾**：信息图生成必须同时满足四个目标——视觉丰富度、精确排版、结构化布局、持续可编辑性，而现有表示只能满足一部分：
  - **SVG 路线**：显式保存几何、层级、渲染顺序与文字，天然可编辑，但自动生成的 SVG 观感僵硬、手工美化难以规模化。
  - **栅格扩散路线**：美学先验强，但把内容与布局压平成一张图，密集文字常被乱码化，局部编辑困难。
  - **"栅格化 SVG 作条件"的折中方案**：只保留粗略位置，丢弃元素归属、遮挡关系与可重组结构，因此无法真正解决冲突。
- **论文主张**：应让"可编辑的合成单元"在整个生成过程中保持存在，而不是事后从像素里反推元素归属；据此提出**结构化美化（structured aestheticization）**的混合范式。

## 2. 方法论

### 2.1 核心思想

把 SVG 保留为**语义、结构、排版与渲染顺序的唯一事实来源**，只让扩散模型负责"非文字内容的美学化"。扩散输出的是**按 z 序排列、互不重叠的可编辑 RGB 图层集合**，最后按 SVG 绘制顺序做 alpha 合成，并叠加由矢量元数据精确渲染的文字层。

### 2.2 问题形式化

- 场景表示为 `S = (E, T, H, z, M)`：`E` 为非文字元素，`T` 为文字与排版，`H` 为父子链接，`z` 为绘制序号，`M` 含元素类型、归一化包围盒与渲染器导出的掩码。
- 每个元素同时保留**全掩码 A_i（amodal，未被遮挡的完整区域）**与**可见掩码 V_i**，二者之差即被前方元素遮挡的隐藏区域，为"删除/平移/z 序调整后露出内容"提供监督。
- 最终产物为 `A = (S, {L̂_g}, R)`，图像 `Î = Over(R_text(T), Comp_z(L̂_1,…,L̂_G))`，即文字层覆盖在按绘制顺序合成的图层之上。

### 2.3 有序非重叠图层集划分（关键设计）

- 目标：不必为每个 SVG 元素开一条扩散路径，又不破坏遮挡正确性。
- 按 `(z_i, i)` 升序处理元素：若元素 i 与任何已处理元素都不重叠，则归入第 1 组；否则归入"与它重叠的已处理元素的最大组号 + 1"。
- 由此保证：**同组元素全掩码互不相交**（不会互相覆盖），**任何重叠关系都严格服从 SVG 绘制顺序**（前方元素绝不会被放进更靠后的组）。
- 组掩码为组内元素掩码的并集；路径数量取决于"重叠层数"而非"元素个数"，显著节省算力。
- 合成采用预乘 alpha 的前到后递推：`P_(g) = P_g + (1-α_g)P_(g-1)`，`α_(g) = α_g + (1-α_g)α_(g-1)`。
- 绘制顺序只决定**合成顺序**，不决定生成顺序：所有组并行去噪，单层可后续平移/删除/换序而无需重生成其他层。

### 2.4 并行协同去噪（避免各层风格漂移）

- 采用 flow matching 的线性插值路径，所有图层共享同一时间步 `t`。
- 初始噪声做**共享 + 私有分解**：`ε_g = √ρ·ε_sh + √(1-ρ)·ε_pr,g`，`ρ ~ U(0.5, 1)`。共享分量拉齐整体色调/光照，私有分量保留层内细节。
- 主损失为按有效层掩码加权的速度场回归：`L_layer = Σ_g m_g‖v_θ,g − u_g‖² / Σ_g m_g`，并由 `x̂_1,g = x_t,g + (1−t)v_θ,g` 得到一步干净估计。

### 2.5 冻结主干 + 可训练适配器（层身份与层间通信）

- 主干为冻结的 MMDiT（同 Ideogram-4），只训练小型适配器，初始化输出为零，因此训练初期不改变预训练行为（沿用 ControlNet / T2I-Adapter 的高效条件化策略）。
- **层身份注入**：`q_g = LN(s_g) + E_z[g] + E_τ[τ_g]`，即 VAE 特征 + 绘制序嵌入 + 主元素类型嵌入，再经 `W_0`（输入端）与 `W_d φ(W_s q_g)`（若干深度）投影为残差。
- **层间通信块（LayerSetCommunicationBlock）**：
  - 每层用 9 组紧凑特征（全图/隐藏区统计量、可见区与边界带均值、2×2 池化空间上下文、类型、包围盒、绘制序、时间步、局部文本上下文、全局特征）汇总为 `h_g`。
  - 注意力打分 `ℓ^a_gh = ⟨W_Q h_g, W_K h_h⟩/√d_a + (w_E)^T E_gh`，其中 `E_gh ∈ R^4` 编码**有向**的"后→前、前→后、父→子、子→父"四种 SVG 关系；softmax 得权重 `π^a_gh`，加权聚合各层 value 后多头拼接得 `e_hg`。
  - 因为是**有向**关系，被遮挡的背景层与前景层可收到不同消息。
- **风格 / 边界双路径回注**：`r_g = σ(γ_sty)·r_sty + σ(γ_bnd)·B_g ⊙ r_bnd`。风格路径输出 2×2 粗网格再上采样，实现整层平滑的外观修正；边界路径乘窄带掩码 `B_g`，只作用于轮廓与跨层接触处；门控偏置初始化为 [−2.0, −2.5]，初始门强约 0.12 / 0.076。

### 2.6 训练目标与精确文字

- 总损失：`L = λ_layer·L_layer + λ_comp·L_comp + λ_hid·L_hid + λ_bnd·L_bnd`。
  - `L_comp`：把各层一步干净估计按全掩码与绘制序合成后，与干净合成目标比较（不经过 VAE 解码整图）。
  - `L_hid`：监督隐藏区域 `H_g = (A_g − V_g)+`。
  - `L_bnd`：匹配祖先边界附近的值与空间梯度。
- **文字完全不进入扩散过程**：所有文字节点从扩散目标中移除，提示词要求留白；生成后由保留的
