## Embedding-Based Educational Taxonomies 

Kia Karbasi 1, Kaveh Karbasi 2*, Gregory Pottie 1

> 1

University of California, Los Angeles 2Tempus AI, Inc. 

Abstract 

Educational taxonomies organize educational content, such as exercise problems, into con-cepts, which are also called skills or knowl-edge components. These taxonomies define learning objectives in educational applications such as intelligent tutoring systems. Developed through human expertise and iterative refine-ment, they also provide fundamental structure for curricula, assessment, and models of stu-dent learning. Recent advances in semantic text embeddings make it possible to construct alternative educational taxonomies computa-tionally from the content itself. In this pa-per, we investigate this possibility by cluster-ing embeddings of math questions to construct embedding-based educational taxonomies. We compare these taxonomies with the existing Common Core State Standards (CCSS)-based knowledge-component taxonomies in two AS-SISTments datasets and evaluate their utility in Deep Knowledge Tracing, a downstream task that relies on taxonomic mappings of questions to knowledge components. The embedding-based taxonomies exhibit substantial but in-complete correspondence with the existing tax-onomies, revealing both preserved and alter-native organizations of educational content. When used for knowledge tracing, they im-prove predictive performance by approximately 3–5 AUC percentage points. These results demonstrate the potential of semantic embed-dings for automatically constructing educa-tional taxonomies that both recover structure present in human-developed taxonomies and provide useful alternative representations for downstream educational modeling. 

1 Introduction 

Educational taxonomies organize educational con-tent, such as exercise problems, into concepts. In educational data and modeling, these concepts are

often called skills or knowledge components (KCs). A taxonomy specifies which questions are treated as instances of related knowledge, giving educators and computer systems a common way to describe content and learning objectives. These mappings provide structure for curricula, assessment, educa-tional applications, and models of student learn-ing (Koedinger et al., 2012). Educational taxonomies are generally developed through human expertise and iterative refinement. The Common Core State Standards, for example, were developed through research, educator and ex-pert input, comparison with existing standards, and public feedback (Common Core State Standards Initiative, n.d.). Such systems encode decisions about which distinctions matter for curricula and assessment, while KC models use those distinc-tions to relate educational tasks, instruction, and student learning (Porter et al., 2011; Koedinger et al., 2012). They are therefore useful educational frameworks, not direct evidence that knowledge is organized in one uniquely correct way. These taxonomies also provide the categories that educational technologies use to organize con-tent and model student learning. Intelligent tu-toring systems connect educational materials to the concepts they are intended to teach or as-sess (Koedinger et al., 2012; Feng et al., 2009). Knowledge tracing uses sequences of questions and responses, along with the concepts assigned to those questions, to estimate student knowledge and predict later performance (Corbett and Anderson, 1995; Abdelrahman et al., 2023). Deep Knowl-edge Tracing (DKT) represents each response with its assigned KC, so earlier performance on a KC can inform later predictions (Piech et al., 2015). Systems that recommend exercises similarly use concept labels and estimates of student knowledge to select individualized practice (Ai et al., 2019). Recent advances in text embeddings make it pos-sible to organize educational content using patterns arXiv:2610.33694v1 [cs.CL] 24 Oct 2026 in the content itself. Embeddings represent ques-tion text in a numerical space where similarities in language and meaning can be compared (Reimers and Gurevych, 2019). Clustering these represen-tations groups nearby questions and assigns each question to one category (Matsuda et al., 2022). In this paper, we use semantic embeddings of math question text to induce embedding-based tax-onomies. Here, a taxonomy refers to a mapping be-tween content or questions and content categories or knowledge components. An induced taxonomy is one constructed from text embeddings. We com-pare these induced taxonomies with the original expert-developed taxonomies and test their utility in a downstream educational task that relies on question-to-KC mappings. We study questions with available text from AS-SISTments 2012 and 2017, two releases from a widely used benchmark family in knowledge trac-ing (Feng et al., 2009; Prihar et al., 2022; Abdelrah-man et al., 2023). We embed the question text, re-duce the representations with principal component analysis (PCA), and cluster them with k-means to construct taxonomies from embeddings. We first compare each taxonomy built from embeddings with the original KC taxonomy supplied with the dataset, using several measures of how the ques-tions are grouped, along with category counts. We then replace the original mapping from questions to KCs with the induced mapping and compare DKT performance using the area under the receiver operating characteristic curve (AUC). Within each dataset, we use the same student-response records, sequence order, student split, DKT model fam-ily, training procedure, Bayesian hyperparameter search, and trial budget. Because an induced tax-onomy may use a different number of categories, the number of KC labels and the number of model parameters tied to those labels may also differ. We tune DKT separately for each taxonomy, so the selected DKT hyperparameters may differ. The code and supplementary materials are available in a public GitHub repository. 1

We ask three research questions: 

RQ1: How closely do the induced and original KC taxonomies correspond? 

RQ2: How does correspondence change as the induced taxonomy uses more categories? 

RQ3: Under which taxonomy does DKT

2 Related Work 

2.1 Educational Taxonomies and Knowledge Components 

KC models connect performance on related tasks to proposed units of knowledge used in teaching and models of student learning (Koedinger et al., 2012). A mapping from questions to KCs there-fore represents a hypothesis about the knowledge required by each question. These models are de-signed for educational use; they are not direct mea-surements of how students think. Learning Fac-tors Analysis shows that student data can be used to evaluate and refine an expert KC model (Cen et al., 2006). Whereas that approach compares possible refinements using student performance, we construct alternative categories from question content. We therefore use the existing KC taxon-omy as a valuable reference, not as the only possi-ble way to group the questions. Expert-developed taxonomies reflect instructional organization; in-duced taxonomies offer complementary groupings derived from question text. Whether these group-ings align with how students organize or learn that content remains an open question. 

2.2 Embedding-Based Clustering and Automated KC Discovery 

Sentence embeddings represent text in a space that supports semantic comparison and cluster-ing (Reimers and Gurevych, 2019). Text similarity can suggest shared content, but it does not by it-self establish a common solution method or role in teaching. SMART uses k-means to cluster repre-sentations of instructional and assessment text in which terms are weighted by their frequency within a document and rarity across documents (TF–IDF), compares the induced categories with expert cat-egories, and evaluates the resulting mapping with an Additive Factors Model (AFM) (Matsuda et al., 2022). KCluster uses language-model-based ques-tion similarity and affinity propagation to derive KCs, compares them with an expert taxonomy, and also evaluates them with AFM (Wei et al., 2025). These are the clustering studies most closely related to our work, although neither uses ASSISTments or DKT. Moon et al. extract KCs from question text and images, group them using embeddings, and evaluate the resulting categories with several knowledge-tracing models, including DKT (Moon et al., 2025). Together, these studies show that educational cat-egories can be constructed from course and ques-tion content. Our study builds on this work by comparing induced and original taxonomies across every tested combination of PCA dimension and number of induced categories ( K), then evaluating the induced mappings in DKT. We also ask whether settings where the taxonomies match more closely tend to produce higher AUC. The core methodol-ogy was developed independently of SMART and KCluster, which we identified as closely related approaches during subsequent literature review. 

2.3 Knowledge Tracing and Text-Aware Student Modeling 

Knowledge tracing uses question–response histo-ries to model how student knowledge develops over time (Corbett and Anderson, 1995; Abdelrahman et al., 2023). DKT uses a recurrent neural network to predict later responses from earlier responses and their KC labels (Piech et al., 2015). For ex-ample, if two questions share a KC label, DKT can use a student’s earlier performance on that KC when predicting a later response; under our method, the same process uses the induced KC labels in-stead. Methods that use question text add question representations to student models while retaining the existing skill labels (Su et al., 2018; Liu et al., 2021). Our approach uses embeddings before DKT is trained: the embeddings define an alternative mapping from questions to categories, and DKT is then trained with the induced labels. This lets us evaluate the mapping in two ways: how closely it matches the original taxonomy and the test AUC achieved by DKT with the induced labels. 

3 Method 

Figure 1 illustrates knowledge tracing with an in-duced taxonomy and the corresponding relabeling used for DKT evaluation. We first derive a map-ping from questions to categories that has one level, using question text alone. We then replace the KC mapping supplied with the dataset with the induced mapping in DKT while keeping the records of stu-dent answers and their order unchanged. 

3.1 Data and Building the Taxonomies 

We use ASSISTments 2012 and 2017, two releases from a widely used benchmark family in knowl-edge tracing (Feng et al., 2009; Prihar et al., 2022; Abdelrahman et al., 2023), because their student interactions can be linked to question text from the ASSISTments Problem Bodies (PB) resource (AS-SISTments Project, n.d.). The full 2012 release contains 179,999 questions and 265 KCs, of which 32,792 questions and 162 KCs belong to the PB text-linked subset. The full 2017 release contains 3,162 questions and 102 KCs, of which 638 ques-tions and 68 KCs belong to the PB text-linked sub-set. These PB subsets are the text-bearing ques-tions and KCs used for our text-based analyses. The largest category in the original 2017 taxonomy, noskill, is a non-substantive placeholder covering 142 of the 638 questions (22%). We exclude AS-SISTments 2009 because its archived release is sen-sitive to preprocessing choices (Xiong et al., 2016). We refer to the dataset-provided question-to-KC mapping in each release as the original taxonomy. Table 1 summarizes the dataset sizes, the category counts tested, and the PCA and K setting reported for each dataset in the taxonomy comparison and DKT results. We convert the HTML in each problem_body to plain text, retain image descriptions, remove scripts and style information, and normalize whitespace. We construct each induced taxonomy from these cleaned question texts. The original KC labels and student responses are not used during construction. Two models embed each question, PCA reduces the vectors, and k-means assigns each question to the nearest cluster center. We evaluate eight PCA dimensions and six values of K, the number of in-duced categories, for each dataset. The tested grids (2012: 50–300; 2017: 20–150) span values below, near, and above the original PB KC counts of 162 and 68, respectively. Each taxonomy assigns one label per question and has one level, not a hierarchy. The taxonomy is constructed from the complete set of linked question texts before splitting students. Following the standard evaluation for knowledge tracing implemented in pyKT (Liu et al., 2022), we split the data by student and evaluate students held out from training. The test set therefore con-tains students not seen during training rather than previously unseen questions. 3.2 Taxonomy Comparison 

We compare questions that have both an original and an induced label using the measures summa-rized in Appendix Table 3. Homogeneity measures whether each induced category primarily contains questions from one original category, while com-pleteness measures whether each original category remains concentrated within one induced category. The remaining measures ask how similarly the two taxonomies group questions, whether pairs of ques-tions stay together, and how different the groupings are overall. Because some scores change simply when the induced taxonomy uses more categories, we interpret them together rather than treating any one score as a complete evaluation. We report in-duced category sizes separately. For the reported 2017 DKT setting, Appendix Figure 5 shows how the 25 largest original categories are distributed across the induced taxonomy. Together, these mea-sures describe how categories stay together, split, or mix across the two taxonomies. Educational usefulness requires separate evidence. 

3.3 DKT Evaluation 

We use DKT because it can use a student’s per-formance on one KC when predicting later an-swers (Piech et al., 2015). KC labels are part of each sequence given to DKT, so replacing the origi-nal labels tests how DKT performs with the induced taxonomy as a whole. We keep every question, re-sponse, and sequence position fixed and replace the original mapping from questions to KCs with the corresponding induced mapping. pyKT maps the resulting labels to consecutive concept iden-tifiers (Liu et al., 2022). Varying K changes the number of labels and can also change the number of model parameters tied to those labels. Figure 1b illustrates this relabeling. We run a separate Bayesian search for the origi-nal taxonomy and for each induced taxonomy de-fined by an embedding model, PCA dimension, and K. Within each dataset, all searches use the same DKT model family, candidate settings, num-ber of trials, student split, training procedure, and selection rule. We reserve 20% of students for final testing, giving an approximate 64/16/20 training, validation, and test split. Within each search, we select the completed run with the highest valida-tion AUC and report its test AUC. The embedding model, PCA dimension, and K are fixed before the search. Testing both embedding models across eight PCA dimensions and six values of K yields 96 induced taxonomies per dataset. Table 2 reports the highest test AUC across the induced taxonomies and the embedding model, PCA dimension, and 

K that produced it; Figure 4 shows the grid of PCA dimensions and K values for that embedding model. Appendix B gives the exact search spaces and training settings. To test whether closer agreement between the taxonomies is related to higher AUC, we analyze the 48 settings of PCA dimension and K in each dataset. At each setting, we average each struc-tural score across the two embedding models and separately average the two test AUC values. We compute Spearman correlations, then repeat the analysis after removing rank patterns linked to PCA dimension and K. We apply the Benjamini– Hochberg correction separately to each set of 15 comparisons (Benjamini and Hochberg, 1995). Ap-pendix D reports the full procedure and coefficients; the analysis shows associations, not causal effects. 

4 Results 

4.1 RQ1: Comparing the Original and Induced Taxonomies 

Table 2 shows much stronger agreement for AS-SISTments 2012 than for ASSISTments 2017 at the two reported settings. For 2012, homogeneity, completeness, and normalized mutual information (NMI) are .930, .717, and .809; for 2017, they are .681, .509, and .582. Neither setting yields the highest adjusted Rand index (ARI) or NMI across all tested settings, showing that the settings reported for DKT are not simply those with the closest match. The full comparison results appear in Appendix C; Appendix Table 5 gives additional comparison scores at these two settings. Appendix Figure 5 shows how the 142 questions in noskill are distributed across the induced taxonomy. Figure 2 shows that questions from large original 2012 categories are often distributed across several induced categories. These divisions may reflect finer mathematical distinctions, recurring wording or templates, or the effect of using more categories. This analysis does not show whether these divisions matter for teaching. 

4.2 RQ2: Effect of the Number of Categories 

Figure 3 shows how homogeneity and complete-ness change as K increases. In ASSISTments 2012, homogeneity generally rises while completeness falls: induced categories become more concen-trated, while each original KC is distributed across more induced categories. In ASSISTments 2017, both averages generally rise over the tested range, but inverse purity and pairwise recall decline, as shown in Appendix Table 6. The measures there-fore capture different effects of using more cate-gories and do not indicate improvement in every aspect of the match. 

4.3 RQ3: Taxonomies and DKT Performance 

Table 2 reports that the highest test AUC among the induced taxonomies exceeds the AUC with the original taxonomy in both datasets. For AS-SISTments 2012, AUC rises from .7367 with the original taxonomy to .7841, a gain of .0474. For ASSISTments 2017, it rises from .7131 to .7403, a gain of .0272. Figure 4 shows that, for

5 Discussion 

The original and induced KC taxonomies organize the same questions using different evidence. The stronger agreement in ASSISTments 2012 suggests that patterns in question text align more closely with the original KC structure there than in AS-SISTments 2017. In both datasets, however, origi-nal categories are split across several induced cate-gories. These splits may reflect mathematical con-tent, recurring wording, or the use of more induced categories; the current analysis cannot determine which explanation is correct. This redistribution may contribute to both the lower cor-respondence and the higher AUC observed in 2017, although the experiment does not isolate its contri-bution from the other changes in the mapping. The DKT results address a different ques-tion: how well each taxonomy supports predic-tion. The induced taxonomy with the highest observed test AUC improves test AUC by .0474 in 2012 and .0272 in 2017, and Figure 4 shows improvement across all 48 PCA and K settings for text-embedding-3-large in both datasets. These results evaluate each induced taxonomy as a whole, including its grouping of questions, number of categories, label frequencies, and model param-eters tied to its labels. They do not show which property drives the gain, and AUC measures predic-tion rather than educational value. After accounting for PCA dimension and K, closer agreement with the original taxonomy is not consistently associated with higher AUC. The negative correlations in 2017 therefore show that lower agreement is sometimes associated with higher AUC, not that disagreement is inherently beneficial. The induced taxonomies are therefore best treated as complements to systems developed by experts. Their similarities and differences can high-light categories or boundaries for expert review. Determining whether these distinctions matter for teaching or reflect how students reason requires evidence from educators, student behavior, and so-lution steps. A comparison with biological taxonomy helps clarify the idea. Biological categories are some-times reconsidered using genetic evidence along-side visible traits (San Mauro and Agorreta, 2010). In the same way, text embeddings provide another source of evidence that may support some expert categories and question others. The comparison has a clear limit: similar question text is not au-tomatically a better basis for curriculum design. Educational categories are useful when they sup-port teaching, assessment, or models of learning. 

6 Future Work 

Future work should extend the analysis to datasets that combine student interactions, question text, and more detailed KC structures. XES3G5M con-tains 5.5 million responses, assigns multiple KCs to some questions, and links broader skills to nar-rower ones. DBE-KT22 provides question text and student responses from a university database course, assigns up to four KCs per question, and includes relationships among KCs (Liu et al., 2023; Abdelrahman et al., 2022). These datasets would support induced taxonomies with multiple labels per question or hierarchical relations among cate-gories. The current ASSISTments datasets would remain useful for evaluating models that explicitly support these richer structures. The induced tax-onomies could also be evaluated in other tasks that use KCs, including measuring progress with prac-tice, identifying students’ relative strengths and weaknesses, and recommending the next practice question (Wang et al., 2020; Cen et al., 2006; Ai et al., 2019). 

7 Conclusion 

We use embeddings of question text to build ed-ucational taxonomies and compare them with the original KC taxonomies in ASSISTments 2012 and 2017. The induced taxonomies preserve much, but not all, of the original structure, with closer agreement in 2012 and consistent changes as the number of induced categories increases. In DKT, the induced taxonomy with the highest observed test AUC improves test AUC by .0474 in 2012 and .0272 in 2017, while closer agreement with the orig-inal taxonomy is not consistently associated with higher AUC across the tested settings. The central result therefore separates two questions: similarity to a taxonomy developed by experts and usefulness for prediction. Taxonomies built from embeddings offer a promising alternative for student models, but their educational value still requires review by experts and evidence from students. 

8 Limitations 

Our analysis covers only ASSISTments 2012 and 2017 questions with linked text. Both datasets come from the same learning platform, so the find-ings may not extend to other platforms, courses, schools, languages, or educational settings. We include only responses tied to questions with text. The procedure for building the taxonomy assigns each question to one induced category. It does not allow several KCs per question, organize KCs from broad to narrow, or model student reasoning. The induced taxonomy may organize questions by wording, templates, formatting, answer type, or source rather than by the mathematics or knowl-edge required to answer them. The comparison measures show how closely the two taxonomies group the same questions rather than their educational value. Purity and homogene-ity can rise simply with the number of categories, and overall scores do not identify which specific splits or mergers matter for instruction. We do not analyze solution steps, inspect individual category boundaries, or ask educators to judge the categories, so we cannot determine the educational value of those differences. The experiments use two models for embedding text, one clustering method, one clustering seed, and a fixed set of PCA dimensions and values of 

K. The observed results may therefore depend on the tested models, clustering procedure, category count, question templates, or distribution of cluster sizes. We use PCA as the only dimensionality-reduction method; alternative reduction methods may produce different induced taxonomies. We do not directly benchmark against prior KC-discovery methods such as SMART or KCluster. We evaluate one DKT architecture. Although all taxonomies use the same records, student split, training procedure, search protocol, and trial bud-get, we tune DKT separately for each taxonomy, so the selected hyperparameters may differ. Chang-ing K also changes the number of KC labels and can change the number of model parameters tied to those labels. Without random-label baselines matched on the number and sizes of categories, the experiment cannot separate grouping by meaning from the effects of category count, how often each label appears, or model size. The reported induced AUC is the highest result across all tested combinations of embedding model, PCA dimension, and K. Because this combination is identified using test AUC, the reported gain sum-marizes the best tested result rather than a combi-nation chosen before looking at test performance. Figure 4 shows the results across the full grid. For each combination, the Bayesian search chooses DKT settings using validation AUC and does not choose the embedding model, PCA dimension, or 

K. Because students rather than questions are held out, test AUC measures performance for new stu-dents on questions used to build the taxonomy, not entirely new questions. Larger K may also make induced labels behave more like coarse question identifiers, which could contribute to higher AUC. Finally, the analysis of taxonomy agreement and AUC shows an association and does not establish that changing agreement causes the AUC gains.
