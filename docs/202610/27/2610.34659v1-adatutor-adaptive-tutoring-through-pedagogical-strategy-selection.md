## 摘要
有效的辅导不仅需要确定提供什么信息，还需要确定以何种形式提供帮助。辅导者可以采用多种教学策略来应对同一学生的错误，并随着交互的推进调整其方法。我们提出比较式教学监督（CPS），这是一种训练框架，用于学习选择最优策略和反馈以促进学生学习。我们在数学与科学推理数据集上评估 CPS。经过五轮辅导后，CPS 优于最强的固定策略基线。学习得到的辅导器可跨数据集迁移，其策略选择也可为另一个基于 API 的辅导器提供指导。

## Abstract
Effective tutoring requires determining not only what information to provide, but also which form of assistance to deliver. A tutor may address the same student error using various pedagogical strategies, adapting its approach as the interaction progresses. We introduce Comparative Pedagogical Supervision (CPS), a training framework to learn to select the optimal strategy and feedback for student learning. We evaluate CPS on math and science reasoning datasets. After five tutoring turns, CPS outperforms the strongest fixed-strategy baselines. The learned tutor transfers across datasets, and its strategy selection can also inform a separate API-based tutor.

## 1. 核心问题与研究动机

- **核心问题**：智能辅导系统（ITS）面临经典的“辅助困境”（assistance dilemma）——既要提供足够的教学支持，又要给学生留出独立解题的空间。对于基于 LLM 的辅导器而言，不仅要决定“给什么信息”，还要决定“以何种教学策略/形式给出帮助”。
- **背景观察**：同一学生错误可以用多种教学策略应对（如提示、步骤脚手架、显式解释、示例、自我解释、对比反馈），而最佳策略取决于学生当前的理解程度与交互进展。固定策略（如始终使用 worked example）虽然可能在某数据集上表现不错，但无法随学生状态动态调整。
- **研究意义**：论文主张把“教学策略选择”本身作为可学习目标，训练一个能逐轮自适应选择策略并生成反馈的辅导器（AdaTutor），并验证其可迁移性。

## 2. 方法论：比较式教学监督（CPS）

### 核心思想
- 在同一个辅导上下文下，让基础模型为**六种教学策略**各生成一个候选反馈，再用**独立模拟学生的多次尝试成功率**来比较哪种策略—反馈组合最有效，将最优者作为监督目标训练辅导器。
- 推理时，辅导器在一次调用中同时输出**策略标签 + 反馈文本**（`[strategy] feedback`），策略标签仅用于可解释性分析，不展示给学生。

### 六种教学策略
| 策略 | 定义 |
|---|---|
| MINIMAL HINT | 简短提示，指向相关概念，不给出下一步操作 |
| STEP SCAFFOLD | 把下一步拆成更小的动作或给出部分设置 |
| EXPLICIT EXPLANATION | 陈述相关规则及其推理依据 |
| WORKED EXAMPLE | 用不同数值的类比问题演示推理，再让学生迁移 |
| SELF-EXPLANATION | 要求学生解释/论证自己的推理 |
| CONTRASTIVE FEEDBACK | 对比学生的错误推理与正确替代方案 |

### 关键技术流程
1. **问题设定**：给定问题 \(x\)、参考解 \(r\)、对话历史 \(H_t\)，辅导上下文 \(c_t=(x,r,H_t)\)；辅导器生成反馈 \(u_t\)，学生产生公开回复 \(v_t\) 与对原题的答案，并与标准答案 \(y\) 核对。
2. **策略生成与打分**：
   - 对每个策略 \(a\in A\)，用基础模型 \(M_0\) 生成反馈 \(u_t^{(a)}\)；
   - 对每个反馈采样 \(K=10\) 次独立学生尝试，计算 pass@1 得分 \(q_t(a)\)（答对比例）。
3. **监督目标构造**：
   - 仅当某策略得分**为正且严格高于其他所有策略**时，保留该训练样本；
   - 目标格式为 `[a*_t] u_t^{(a*_t)}`，即策略标签 + 对应反馈。
4. **多轮监督**：
   - 用 \(\epsilon\)-探索继续交互：以 \(1-\epsilon\) 选择最高分策略，以 \(\epsilon\) 随机选其他策略（实验中 \(\epsilon=0.5\)）；
   - **训练目标始终使用最高分策略**，与“实际继续交互所用策略”解耦，从而分离“目标选择”与“遇到哪些辅导情境”。
5. **训练与推理**：
   - 用 LoRA 微调 \(M_0\)；
   - 推理时一次生成策略标签与反馈，学生回复后基于更新后的对话再次选择策略，实现逐轮自适应。

### 有状态学生模拟器（实验基础设施）
- 构建**知识组件（KC）库**：从训练题参考解中分解推理步骤、聚类、生成并合并 KC 候选。
- 为部分 KC 生成**错误信念**（misconception），经筛选后构造三类学生画像：知识缺口型、误解型、混合型。
- 学生模拟采用**两次 LLM 调用**：第一次根据反馈更新 KC 状态，第二次在固定状态下生成答案与公开回复；公开回复进入辅导对话，答案单独判分。
- 使用 Qwen2.5-32B-Instruct 作为学生模拟器，Qwen2.5-7B-Instruct 作为教师模型。

## 3. 实验设计

### 数据集与场景
- **GSM8K**（小学数学应用题）、**SVAMP**（数学应用题变体）、**ScienceQA**（自然科学/社会科学/语言选择题）。
- 每个数据集构造 **15 个学生画像**（5 知识缺口 + 5 误解 + 5 混合），每个画像评估 200 道题；GSM8K/SVAMP 共享 KC 库与画像。
- 每次交互最多 **5 轮辅导**，学生答对或达到轮数上限即结束。

### 评估指标
- **累积准确率 \(A_t\)**：到第 \(t\) 轮为止已解决的学生—问题对比例；
- **纠正率**：初始错误中被解决的比例，\(\text{CorrectionRate}=(A_5-A_0)/(1-A_0)\)；
- 辅助指标：相对初始准确率的增益 \(A_5-A_0\)。

### 对比基线
- **6 种固定策略辅导器**（每种策略贯穿整个交互）；
- **PROMPT SELECTOR**：给 LLM 展示六种策略定义，提示其每轮选择最合适的策略；
- **SocraticLM**（7B 检查点，苏格拉底式提问）；
- **TutorRL**（7B 检查点，多轮 RL 训练的辅导策略）。

### 主要实验组
- 三个数据集的主辅导性能对比；
- 按学生类型（知识缺口/误解/混合）的策略效果分析；
- “学生类型 oracle”对比（按类型选固定最强策略）；
- 逐轮策略选择分布分析；
- 对话上下文消融（全历史/最新交换/最新学生回复/仅问题）；
- 首轮策略选择 vs. 反馈生成的贡献拆解；
- 跨数据集迁移（3×3）；
- 策略选择迁移到 GPT-4.1-mini API 辅导器；
- 响应质量评估（LLM Judge + 人工标注）；
- 训练侧消融（结果构造方式、探索率 \(\epsilon\)、目标选择与采样、检查点选择）。

## 6. 主要结论与发现

- **主性能**：五轮辅导后，CPS 在 GSM8K、SVAMP、ScienceQA 上分别达到 **72.7%、82.5%、64.1%**，比最强固定策略（GSM8K/SVAMP 为 WORKED EXAMPLE，ScienceQA 为 CONTRASTIVE FEEDBACK）分别高 **6.3、2.6、10.1 个百分点**；相对 TutorRL 高 10.4/8.2/3.5 点，相对 SocraticLM 高 9.8/13.5/7.5 点。
- **策略确实在变化**：相邻轮次策略不同的比例为 54.3%–62.3%；67.3%–84.9% 的会话至少发生一次策略切换；GSM8K 上 WORKED EXAMPLE 从首轮 80.5% 降至第五轮 35.7%，CONTRASTIVE FEEDBACK、HINT、STEP SCAFFOLD 占比上升。
- **按学生类型固定策略不够**：用测试结果构造的“学生类型 oracle”在每个数据集内仍选同一策略，纠正率（64.9%/78.0%/46.2%）明显低于 CPS（71.4%/80.9%/58.0%）。
- **对话上下文有帮助但程度因数据集而异**：GSM8K 上去掉对话使准确率从 72.7% 降至 50.6%；SVAMP 从 80.2% 降至 72.3%；ScienceQA 反而“仅问题”条件最高（66.7% vs. 63.9%）。
- **策略选择是主要贡献**：首轮对比中，使用相同固定策略反馈时，CPS 的策略选择比 Prompt Selector 高 34.1/33.8/13.8 点；使用各自生成的反馈再额外提升 2.1/3.5/7.9 点。
- **跨数据集迁移**：GSM8K↔SVAMP 迁移较强（SVAMP 训练的辅导器在 GSM8K 上达 75.5%，超过 GSM8K 域内训练的 72.7%）；数学与科学之间的迁移明显较弱。
- **策略选择可迁移到 API 模型**：用 CPS 的策略标签指导 GPT-4.1-mini 生成反馈，最终准确率 89.9%，比所有固定策略至少高 7.3 点；相对 API Prompt Selector 首轮高 5.3 点（95% CI [1.2, 9.7]），最终高 2.0 点（CI [−2.0, 6.1]，不显著）。
- **学生模拟器验证**：相关反馈可使目标 KC 状态改变 40/40，而 retry-only、无关、错位、直接给答案等对照条件均为 0/40；状态更新后在新题上的准确率从 5.0% 提升至 67.7%，说明模拟器的状态变化具有选择性且可迁移。

## 7. 优点

- **问题定位清晰**：把“教学策略选择”从隐式的提示工程提升为显式的可学习目标，直接回应辅助困境。
- **监督信号设计巧妙**：用同一上下文下多策略反馈的**结果对比**构造偏好式监督，避免人工标注策略优劣；只保留唯一最高正分样本，减少噪声。
- **训练与探索解耦**：训练目标始终取最优策略，而交互继续使用 \(\epsilon\)-探索，兼顾数据覆盖与目标质量。
- **有状态学生模拟器**：将 KC 状态更新与回复生成分离，支持对同一对话状态比较不同反馈，提升了实验可控性与可复现性。
- **分析维度丰富**：不仅报告总体准确率，还拆解策略选择 vs. 反馈生成、按学生类型分层、逐轮策略演化、上下文消融、跨数据集与跨模型迁移，证据链较完整。
- **可解释性**：策略标签随反馈一起生成，便于分析辅导行为，且不增加推理时的候选选择开销。

## 8. 不足与局限

- **仅验证于模拟学生**：作者在 Limitations 中明确承认，当前结果**不构成对人类学习的证明**；模拟学生的行为由 LLM 驱动，可能与真实学生的认知更新机制存在偏差。
- **学生模拟器忠实度有限**：人工评估中，学生 KC 标签与 LLM 判断的一致率为 84.0%，但人类标注者之间的成对一致率仅 41.8%，说明学生状态判断本身存在较大主观性；模拟器可能不完全遵循指定误解。
- **跨领域迁移弱**：数学与 ScienceQA 之间的迁移显著低于 GSM8K↔SVAMP，说明学到的策略选择对领域/学生困难分布较敏感，通用性有限。
- **API 迁移证据偏弱**：GPT-4.1-mini 实验仅用 247 题，最终增益相对 Prompt Selector 不显著（置信区间跨 0），结论应谨慎解读。
- **ScienceQA 细节不完整**：KC 数量、受影响 KC 数等在表中标为 “TBC”，影响复现与横向比较。
- **算力与成本披露不足**：未报告 GPU 型号、数量与训练时长；数据收集需约 19 万次模型请求，实际部署成本可能较高。
- **策略空间固定为六种**：策略集合来自认知科学文献，但未探索更细粒度或领域特定的策略；策略标签由模型自行生成，存在标签与实际行动不完全一致的风险（论文报告策略出现率 96.1%、主策略一致率 92.8%）。
- **基准与评估依赖 LLM Judge**：虽有人

工评估作为补充，但人工研究样本量较小（每项 20 例、每例 3 票），且标注者间一致性有限，LLM Judge 的评分可能受提示设计、模型偏好与呈现顺序影响。因此，响应质量与教学合理性的结论应视为初步证据，而非稳健的人类教学效果验证。

- **评估窗口与任务范围有限**：实验最多 5 轮辅导，题目以短程、有明确答案的数学应用题与科学选择题为主；对长程学习、开放式任务、真实课堂中的知识保持与迁移效应尚未验证。
- **教师模型与学生模拟器同源风险**：教师模型 Qwen2.5-7B 与学生模拟器 Qwen2.5-32B 属于同一模型家族，可能共享表达与推理偏好，使辅导器学到适配该模拟器的策略，而非普遍有效的教学策略；GPT-4.1-mini 迁移实验只能部分缓解这一担忧。
- **策略标签可靠性存在边界**：策略标签由模型自行生成，论文报告的策略出现率 96.1%、主策略一致率 92.8% 说明多数情况下可识别，但仍可能存在标签漂移；基于标签的策略演化与归因分析需谨慎解读。
- **训练样本筛选带来选择偏差**：仅保留“唯一最高正分”样本，会排除平局、微弱优势与负分情境，使训练分布偏向区分度高的辅导情境；真实课堂中常见的小幅渐进帮助可能被低估。
- **真实部署成本与延迟仍需评估**：训练阶段需对每个上下文生成六种策略反馈并多次采样学生尝试，数据构造开销较大；推理阶段虽只需一次生成，但模拟器基础设施、模型调用与安全监控成本在实际教育部署中不可忽视。
- **伦理与公平性讨论不足**：论文未深入讨论学生数据隐私、错误引导的风险、策略选择对不同背景学生的公平性，以及过度依赖自动化辅导可能带来的动机与教师角色问题；真实部署前需人类教师监督与安全评估。

## 9. 总体评价与启示

- **定位与贡献**：论文将“教学策略选择”从隐式提示工程提升为显式可学习目标，提出比较式教学监督（CPS），并用有状态学生模拟器构造可控实验。其核心贡献不只是某个辅导器检查点，而是“如何用结果比较构造策略偏好监督”的方法论。
- **证据强度**：主实验、按学生类型分层、逐轮策略分布、上下文消融、策略选择与反馈生成的贡献拆解、跨数据集与跨模型迁移、训练侧消融等构成了较完整的证据链，较好支持“自适应策略选择优于固定策略与简单提示选择”的结论。但证据主要来自 LLM 模拟学生与短程评估，尚不足以证明对人类学习有效。
- **适用边界**：当前方法最适合具有明确答案、可分解知识组件、可模拟学生状态的短程辅导任务；对跨领域迁移、长程学习、开放任务与真实课堂交互，外推需谨慎。
- **对未来研究的启示**：后续工作应优先引入真实学生实验与更长周期的保持测试；使用异源模型或真实学生行为校准模拟器；扩展并校准策略空间；系统报告算力、延迟与部署成本；并补充公平性、隐私与教师监督机制的研究。
- **一句话总结**：AdaTutor 提供了一套有说服力的“策略选择可学习化”训练框架与实验范式，但其当前结论应理解为在模拟环境中的方法有效性验证，而非真实教学效果的最终证明。
