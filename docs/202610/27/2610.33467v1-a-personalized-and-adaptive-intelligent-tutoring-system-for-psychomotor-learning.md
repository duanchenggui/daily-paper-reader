## 摘要
智能辅导系统（ITS）已在认知领域提升了学习者的动机与个性化水平，但将这些收益扩展到心理运动任务仍具挑战性。现有的心理运动ITS依赖于在教学前构建或每个模块仅更新一次的学习者模型，尚未明确如何利用学习者认知状态的实时评估来实现更细粒度的个性化。心理运动学习涉及多个辅导目标，包括使自信与表现相匹配、依据耶克斯-多德森定律校准工作负荷，以及推动技能向更高学习阶段发展。如何为学习者平衡这些目标，并随时间调整该平衡，仍是一个开放问题。本研究提出并评估了一种在线个性化算法，该算法持续重新确定辅导目标的优先级，以匹配学习者不断变化的需求。该算法受actor-critic启发，并非对目标等权加权，而是利用近期自信、工作负荷和表现的测量值动态更新奖励权重。这些权重用于一个多输入、多输出的认知控制框架，该框架通过基于模型的规划合成学习者特定的辅导策略。该方法在一项以二维四旋翼飞行器着陆任务为内容的人体受试研究（N = 40）中进行了评估。对所学奖励权重的聚类揭示了学习者之间不同的优先级模式，表明该算法捕捉到了学习者需求的异质性。权重变化更显著的学习者倾向于达到更高的最终表现，而权重持续强调工作负荷校准的学习者取得了最强结果。这些发现推进了心理运动ITS中的在线学习者建模与基于控制的个性化，展示了自适应辅导如何通过使教学决策与学习者不断变化的认知和表现状态相一致来更好地支持学习。

## Abstract
Intelligent tutoring systems (ITSs) have advanced learner motivation and personalization in cognitive domains, but extending these gains to psychomotor tasks remains challenging. Existing psychomotor ITSs rely on learner models built before instruction or updated once per module, leaving open how to use real-time assessments of learner cognitive state for finer-grained personalization. Psychomotor learning involves multiple tutoring objectives, including calibrating self-confidence to performance, calibrating workload per the Yerkes-Dodson Law, and driving skill progression toward higher learning stages. How to balance these objectives for learners, and adjust that balance over time, remains open. This study proposes and evaluates an online personalization algorithm that continuously reprioritizes tutoring objectives to match learners' evolving needs. Rather than weighting objectives equally, the actor-critic-inspired algorithm dynamically updates reward weights using recent measures of self-confidence, workload, and performance. These weights inform a multi-input, multi-output cognitive control framework that synthesizes learner-specific tutoring policies via model-based planning. The approach was evaluated in a human-subject study (N = 40) with a 2D quadrotor landing task. Clustering of the learned reward weights revealed distinct prioritization patterns across learners, indicating the algorithm captures heterogeneity in learner needs. Learners whose weights shifted more substantially tended to reach higher final performance, and those whose weights consistently emphasized workload calibration achieved the strongest outcomes. These findings advance online learner modeling and control-based personalization in psychomotor ITSs, showing how adaptive tutoring can better support learning by aligning instructional decisions with learners' evolving cognitive and performance states.

## 2. 方法论

### 2.1 核心思想
- 受 **actor-critic 强化学习架构启发**：将奖励权重 α 视为高层 actor 参数，用以调制奖励结构；由近期学习者数据计算的目标函数 V₁、V₂、V₃ 作为 critic 信号，评估各辅导目标的满足程度。
- 与经典 actor-critic 不同：**不通过在线交互更新策略**，而是先用梯度下降更新奖励权重，再用**基于模型的 Q-iteration** 重新求解最优策略，从而规避数据稀疏、状态-动作覆盖不足、非平稳性及人类在环探索风险等问题。

### 2.2 学习者模型（MDP）
- 使用马尔可夫决策过程 $(S, A, T, R, \gamma)$ 建模学习者状态动态。
- 状态包括：自信心 $s_{SC}$（低/中/高）、工作负荷 $s_W$（低/中/高）、学习阶段 $s_{LS}$（LS1、LS2、LS3,4 合并）。
- 动作：自动化辅助 $a_\theta \in \{\theta_{off}, \theta_{on}\}$；反馈语气 $a_\tau \in \{\tau_{neg}, \tau_{neu}, \tau_{pos}\}$。
- 假设三个状态维度**相互独立**，联合转移概率为各维度转移概率之积（式 6）。
- 模型参数通过 MATLAB 遗传算法最大化观测状态-动作序列似然进行估计，并采用 5 折交叉验证。

### 2.3 多目标加权奖励
- 加权奖励函数：$\bar{R}(s,a) = \alpha_1 R_1 + \alpha_2 R_2 + \alpha_3 R_3$（式 7），其中 α 为凸组合权重（$\sum \alpha_i = 1, \alpha_i \geq 0$）。
- $R_1$：自信校准奖励（依据自信状态与学习阶段的匹配程度，对辅助动作和反馈语气分别赋分，见表 VI/VII）。
- $R_2$：工作负荷校准奖励（依据学习阶段与工作负荷匹配程度，仅辅助动作进入，见表 VIII）。
- $R_3$：学习阶段进阶奖励（辅助关闭时高阶段得分高；辅助开启时低阶段得分高，见表 IX）。

### 2.4 奖励权重自适应算法（Algorithm 1）
1. **计算近期统计量**（最近 10 次试验）：平均自报告自信 $\overline{SR}_{SC}$、平均工作负荷 $\overline{SR}_W$、平均缩放分数 $\bar{J}$、分数标准差 $\sigma_J$。
2. **定义目标函数**：
   - $V_1 = (\overline{SR}_{SC} - \bar{J})^2$（式 9，惩罚过度/不足自信）
   - $V_2 = (\overline{SR}_W - (100 - \bar{J}))^2$（式 10，惩罚工作负荷与表现不匹配）
   - $V_3 = \max(0, \zeta - \bar{J})^2 + \lambda \sigma_J$（式 11，ReLU 惩罚 + 方差惩罚）
3. **构造目标权重分布**：$\tilde{\alpha}_i = \frac{\exp(\kappa V_i)}{\sum_j \exp(\kappa V_j)}$（式 12），使未满足的目标获得更大权重。
4. **优化权重**：最小化 $L_\alpha = D_{KL}(\alpha \| \tilde{\alpha}) + \beta D_{KL}(\alpha \| \alpha_{prior})$（式 13），通过 softmax 参数化 $\alpha = \text{softmax}(z)$，对 $z$ 做梯度下降（式 14）。
5. **策略合成**：用更新后的 $\bar{R}_{\alpha^\star}$ 执行 Q-iteration 求解 $Q^\star$ 与 $\pi^\star$。
- 实验参数：$\zeta = 85$、$\kappa = 0.25$、$\beta = 0.01$。

### 2.5 心理运动任务与学习量化
- **任务**：2D 四旋翼着陆模拟器，要求安全着陆（速度 $|v| \leq 15$ m/s、滚转角 $|\phi| \leq 5°$），通过 T.Flight Hotas 4 控制器操作。

- **连续性能分数**：$S = (S_{t,p} + S_{t,v} + S_{t,\theta} + S_{t,MMD_{LS4}})/4 \times 10$（式 1），满分 1000；750 分表示成功着陆，850 分表示轨迹接近熟练者。

## 6. 主要结论与发现

- **RQ1（是否产生不同权重模式）**：是。k=3 聚类得到三个清晰模式——Cluster 1 优先自信校准、Cluster 2 优先工作负荷校准、Cluster 3 优先学习阶段进阶；k=4 时额外出现一个平衡自信与工作负荷校准的簇。说明算法捕捉到了学习者需求的**异质性**。
- **RQ2（权重是否动态变化）**：是。40 人中有 **16 人**的权重向量在阶段间发生跨簇转移，表明辅导策略随学习者需求动态调整。change 组最终平均分 814.39（标准差 170.96），多数超过 750 的安全着陆阈值。
- **RQ3（是否成功按需优先排序）**：基本支持。
  - **W 组**（持续强调工作负荷校准）表现最强：最终均分 **933.95**（标准差 35.24），且最终自信最高（88.50），但与 LS 组相比，其工作负荷（45.75）相对高表现而言偏高，存在“负荷-表现失校准”，恰说明该组被持续分配了工作负荷校准目标。
  - **LS 组**（强调学习阶段进阶）最终均分最低（**651.66**，标准差 235.35），但自信（55.29）与工作负荷（52.00）相对其表现是校准的，说明该组的学习阶段目标确实是最未满足的目标。
  - **SC 组**（强调自信校准）最终均分 793.27，但自信仅 46.67，显著低于 W 组（p=0.0016），说明自信是其最未校准的目标。
  - ANOVA 显示组间在**最终表现**（p=0.0129）与**最终自信**（p=0.0019）上显著，在表现变化（p=0.4231）与最终工作负荷（p=0.8339）上不显著。
- **总体结论**：权重变化更显著的学习者倾向取得更高最终表现（W 组除外）；持续强调工作负荷校准的学习者结果最强；算法能按学习者需求合理重排辅导目标。

- **部分结果存在解释张力**：W 组“表现最好但工作负荷相对表现偏高”、LS 组“表现最低但自信与负荷相对校准”、SC 组“表现中等但自信显著偏低”，这些模式虽可用“被持续分配的目标即最未满足的目标”自洽解释，但同样可能反映**分组本身是对结果的事后划分**（post-hoc clustering），存在循环论证风险；此外，change 组（16 人，占 40%）未被纳入核心假设检验，样本被“切分”后各组结论的代表性进一步削弱。
- **自报告测量的局限**：自信与工作负荷均依赖学习者主观自报告，未使用生理或行为指标（如眼动、心率变异性、反应时）交叉验证，难以排除社会赞许性或量表理解差异带来的偏差。
- **学习阶段判定的间接性**：学习阶段由轨迹核嵌入分类器在线判定，其准确性未在文中给出独立的分类性能报告（如准确率、混淆矩阵），而该判定直接决定 R₁、R₂、R₃ 的取值，误差会沿奖励链路传导。
- **策略更新的粒度较粗**：每 10 次试验才更新一次权重并重新求解策略，属于“分段静态”个性化，与论文所批评的“每模块仅更新一次”相比虽有改进，但仍非真正的逐试次自适应；文中亦未报告更新前后策略的实际差异幅度。
- **缺少与基线学习曲线的比较**：仅有“前 2 次 vs 最后 5 次”的表现变化，未与无辅导条件下的自然学习曲线对照，因此无法区分收益来自个性化算法还是单纯练习效应。

## 9. 对研究与实践的启示

- **方法论启示**：把“多目标辅导中如何分配优先级”形式化为一个**低维权重学习问题**，是本文最具迁移价值的思路。它把难以直接优化的人类学习目标（自信校准、负荷校准、阶段进阶）转化为可微的损失，再用基于模型的规划求解策略，为“人类在环强化学习”提供了一条规避在线探索风险的可行路径。
- **设计启示**：三个目标函数 V₁–V₃ 的构造方式（失校准平方误差 + ReLU 阈值惩罚 + 方差惩罚）具有较强的可复用性，可迁移到其他需要“表现—状态匹配”的适应性教学场景（如编程教育中的认知负荷管理、语言学习中的焦虑调节）。
- **评估启示**：本文的评估范式（对学到的权重做聚类 → 按簇分组 → 组间统计比较）为“个性化算法缺乏对照组时如何呈现证据”提供了一种可借鉴但需谨慎使用的分析模板；后续研究应在此基础上补充对照条件。
- **实践启示**：结果提示“持续强调工作负荷校准”可能与最佳表现相关，而“过早强调阶段进阶”可能带来较大表现方差，这对自适应训练系统的目标调度顺序设计具有参考意义，但需在更大样本与更多任务中复核。

## 10. 总体评价

- **贡献定位**：本文属于“方法提出 + 小规模人体验证”型工作，核心贡献在于**问题形式化与算法框架**（在线重加权 + 基于模型策略重求解），而非严格的因果效应证明。
- **证据强度**：中等偏弱。方法论证充分、理论根基扎实、实验流程规范，但**缺乏对照组、样本量小、分组为事后聚类**三项因素共同限制了结论的因果解释力；作者对此亦有自述。
- **写作与透明度**：奖励函数表（表 VI–IX）、算法伪代码、超参数取值交代较清楚，方法部分可复现性较好；但算力信息、分类器性能、消融实验的缺失降低了完整度。
- **适用读者**：适合关注智能辅导系统、人类在环强化学习、多目标奖励设计、心理运动技能训练的研究者与系统设计者参考；不宜作为“个性化辅导显著优于非个性化辅导”的直接证据引用。

## 12. 后续可延伸的研究方向

1. **补充对照实验**：设置均匀权重、随机权重、固定优先级与传统非个性化 ITS 四类基线，以分离个性化算法的因果增益。
2. **提高更新频率**：将权重更新从“每 10 试次”细化到滑动窗口逐试次更新，并报告策略变化的幅度与稳定性。
3. **放松独立性假设**：建模自信、工作负荷、学习阶段之间的耦合转移（如使用因子化 MDP 或耦合 HMM），检验独立性假设带来的偏差。
4. **多模态状态评估**：引入生理与行为信号替代或补充自报告，降低主观偏差。
5. **超参数消融与敏感性分析**：系统考察 κ（目标锐度）、β（先验正则强度）、ζ（进阶阈值）、λ（方差惩罚）对权重轨迹与学习结果的影响。
6. **跨任务泛化验证**：在手术模拟、驾驶、体育等更复杂的心理运动任务中复现，检验方法的可迁移性。
7. **长期学习效果**：增加延迟后测（retention test）与迁移测试，区分即时表现提升与真实技能获得。
