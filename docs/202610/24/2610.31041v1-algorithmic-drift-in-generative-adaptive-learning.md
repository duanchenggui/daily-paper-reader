## 摘要
生成式人工智能有望使个性化辅导大众化，但自适应系统的纵向稳定性仍缺乏充分的理论化。当前的伦理讨论主要关注静态偏差。本文认为，一种不同的威胁在于算法漂移：这是一个反馈回路，其中微小的、按人口统计特征不对称的观察误差会随时间累积，演变为系统性不平等。我们有三项贡献。第一，我们将算法漂移形式化为一个学习者—导师耦合动力系统。第二，我们通过基于智能体的蒙特卡洛模拟佐证这一理论，其中由透明的在线跟踪器或 LSTM 深度知识追踪网络驱动基于 IRT 的课程策略。第三，我们引入时间公平稳定器（TFS），这是一种定期重新探测学习者能力的定向干预，并使用显式群体公平指标和复制级推断将其与标准探索基线进行基准比较。在建模环境中，TFS 在通用探索无法做到的情况下弥合了成绩差距，并且我们刻画了其成功的条件。我们区分了哪些是分析上已确立的、哪些是在模拟中展示的，以及哪些仍有待用真实学习者验证。我们的结果将教育中的算法公平重新界定为闭环的一种时间属性，而非部署时的一次性勾选项。

## Abstract
Generative artificial intelligence promises to democratize personalized tutoring, yet the longitudinal stability of adaptive systems remains under-theorized. Current ethical discourse focuses on static bias. This paper argues that a distinct threat lies in algorithmic drift: a feedback loop in which minor, demographically asymmetric observation errors compound over time into systemic inequities. We make three contributions. First, we formalize algorithmic drift as a coupled learner--tutor dynamical system. Second, we corroborate this theory with an agent-based Monte Carlo simulation in which either a transparent online tracker or an LSTM deep-knowledge-tracing network drives an IRT-based curriculum policy. Third, we introduce the temporal fairness stabilizer (TFS), a targeted intervention that periodically re-probes learner capability, and benchmark it against standard exploration baselines with explicit group-fairness metrics and replication-level inference. Within the modeled environment, TFS closes the achievement gap where generic exploration does not, and we characterize the conditions under which it succeeds. We separate what is established analytically, what is demonstrated in simulation, and what remains to be validated with real learners. Our results reframe algorithmic fairness in education as a temporal property of a closed loop rather than a deployment-time checkbox.

- **核心命题**：真正的威胁是**算法漂移（algorithmic drift）**——一个闭环反馈回路：LLM 评分器对非标准英语（非母语/方言）作答产生**不对称假阴性**（把正确判为错误）→ 知识追踪器低估该群体能力 → 生成式策略投放更简单的补救性内容 → 学生在低于其最近发展区（ZPD）的内容上"成功"→ 反过来"证实"了系统的悲观预测 → 真实能力增长停滞。
- **问题重述**：算法偏见由此从"公平问题"变为"可持续性问题"——教学资源被错配，有能力的学生被系统性低挑战、低技能化。公平应从**部署时的一次性勾选项**，重构为**闭环系统的时间属性**。

  - RQ1：初始（t=0）公平的自适应策略在何种条件下随 t→T 分化？能否**解析刻画**而非仅经验观察？
  - RQ2：当代 LLM 作为零样本自由文本评分器，是否真的存在模型假设的不对称假阴性？量级多大？
  - RQ3：轻量级、公平感知的内容策略正则能否打断回路？与标准 RL 探索策略相比如何？

## 2. 方法论

### 2.1 总体思路
采用"**解析理论 + 智能体蒙特卡洛模拟 + 真实评分器测量**"三线互证：先用约简均值场模型证明分岔存在，再用高保真模拟验证机制与干预，最后用真实开源 LLM 测量触发漂移的噪声参数 ε。

### 2.2 学习者–导师耦合动力系统（模拟环境）
- **设定**：部分可观测马尔可夫决策过程（POMDP）；N=10,000 个合成学习者智能体，T=100 时间步，K=50 个知识组件，难度 βⱼ~U[0,1]。
- **作答模型**（IRT 双参数 logistic）：P(cᵢⱼ=1) = 1/(1+exp(−a(θᵢ(t)−βⱼ)))，a=0.7（a=1 退化为 Rasch）。
- **能力更新**：θᵢ(t+1) = clip[0,1]{ θᵢ(t) + αᵢ·g(θᵢ(t)−βₜˢʳᵛ) − λθᵢ(t) }
  - g(·) 为 ZPD 增益核：主设定用高斯核 g(Δ)=exp(−Δ²/(2ω²))，ω=0.12；理论分析用硬指示核 I(|Δ|<ω)。
  - 遗忘因子 λ=0.002；学习率 αᵢ~N(0.02,0.005)（截断为正）；clip 保证与难度同尺度。
- **群体构造**：参照组 80%（标准语言模式）、受保护组 20%（非标准语言标记），**基线能力等价** θᵢ(0)~N(0.5,0.1)，使任何后续分化可归因于观测通道而非先验差异（作者明确称此为"识别装置"，非对真实群体的断言，4.7 节放松该假设）。
- **观测噪声通道**：参照组无噪；受保护组 P(a_obs=0 | a_true=1, sᵢ∈S_prot) = ε（记忆less 伯努利翻转，基准 ε=0.05）。

### 2.3 两类知识追踪估计器
- **透明在线追踪器**（主实验）：Rasch 模型的随机梯度极大似然更新，θ̂ₜ₊₁ = clip[θ̂ₜ + η(a_obs,t − σ(a(θ̂ₜ−βₜ)))]，η=0.2。
- **LSTM 深度知识追踪（DKT）**：隐藏维 200，输入 (βₜ, a_obs,t)，输出全题库预测成功概率，再反读出最拟合的 Rasch 能力；在 24,000 条无噪异质种群交互日志上预训练 8 轮后**冻结入环**。
- **内容策略**：准静态地令服务难度 βₜ₊₁ = θ̂ₜ₊₁（追踪估计 ZPD，取题库最近项）。

### 2.4 理论结果（命题 1 与推论 1）
- **设定**：单均值场知识组件，Rasch 链接，策略以固定教学成功率目标 p⋆ 调整难度，使 (1−ε_g)σ(θ−β)=p⋆，得服务偏移 c_ε = σ⁻¹(p⋆/(1−ε_g))，即 β = θ − c_ε。
- **临界噪声阈值**：ε⋆ = 1 − p⋆/σ(ω)（默认标定下 ε⋆≈0.040）。
- **三分结论**：
  - (i) 0<ε<ε⋆：受保护组被服务**更简单**内容，难度亏空 δ(ε)=c_ε−c₀ 严格随 ε 递增，但两组仍在 ZPD 内、仍在学习（"有进步但被低挑战"区制）；
  - (ii) ε≥ε⋆：服务难度离开 ZPD，学习指示函数 I(·)=0，能力**几何衰减** θₜ₊₁=(1−λ)θₜ；
  - (iii) 渐近能力差距 Δ∞(ε) 对 ε 单调不减，且在 ε⋆ 处**不连续**——即从"低挑战"到"被困且衰退"的**分岔**。
- **推论 1**：若每 τ 步强制投放一个落在 ZPD 内的探针，则 θₜ₊τ ≥ (1−λ)^{τ−1}θₜ + α，能力有与陷阱条件无关的下界——周期性 ZPD 重入可阻止无界几何衰减。这也解释了为何"仅降低平均误差"不够，必须保证周期性 ZPD 重入。

### 2.5 干预：时间公平稳定器（TFS）
- 为每个学习者维护**悲观计数器 κ**：当估计能力低于同辈估计的 60 分位超过边际 m（m=0.10）且未达掌握上限时 κ+1，否则清零。
- κ≥τ（τ=5）时触发**诊断探针**：服务难度 β_probe = θ̂ + δ（δ=0.10），即**略高于**（可能已被压低的）估计，而非盲目顶格探测；随后 κ 清零。
- **能力棘轮（ratchet）**：探针通过则 θ̂ ← max(θ̂, β_probe)，在两次探针之间抵抗有偏观测通道。
- **与通用 RL 探索的本质区别**：ε-greedy / UCB / Thompson 探索是为**降低估计不确定性、最大化平均回报**，一旦（含噪）信号收集完即回退；TFS 探索是为**检验一个公平假设**（持续补救是否源于评分摩擦而非真实缺陷），由**回路持续时间**而非不确定性触发，且通过棘轮保留已证明的能力。

### 2.6 评估指标
- **漂移散度 D**：真实掌握度与系统估计掌握度的平均绝对错位（认知/认识论退化度量）。
- **差距扩大 Δ**：两组真实学习增益之差。
- **假阴性误分类率**：真实能力高（θ>0.7）却被投放补救内容（β<0.4）的步数比例。
- **五项群体公平指标**：暴露差距 G_β（服务难度均值差）、ZPD 可及性差距 G_Z、估计偏差差距 G_b（带符号校准误差差）、补救误分类差距 G_FN（机会均等对比）、增益比 ρ（差异化影响对比）。
