## 摘要
贡献：本研究表明，一种由不同情感与认知反馈信号引导的共享提示优化流程，可以在不更新执行器参数的情况下，提高留出参考一致性及多标签分类性能，同时降低情感生成的变异性。背景：工业4.0增加了对跨相互关联的计算与工程领域个性化技术教育的需求，而提示敏感性和生成变异性使教学对话与学习结果的可靠解释变得复杂。研究问题：本研究考察了任务特定反馈是否能够在不更新执行器参数的情况下改善情感参考一致性、生成一致性和认知分类。方法：一个次级语言模型利用执行器输出与模型生成情感参考之间的差异（针对四段对话）以及针对70个学习结果标注的布鲁姆标签，对执行器提示进行修订；分别使用100段EduTalk对话和1,000个结果的独立集合支持留出比较。小型优化集、未经效验的情感参考以及缺乏学习者结果测量限制了结果解释。发现：情感平均绝对误差从0.742降至0.702，平均生成标准差从0.307降至0.238，而布鲁姆微观F1从0.687升至0.893，精确匹配子集准确率从0.418升至0.636。这些发现支持将提示优化作为开发自适应技术教学的候选方法，但其对劳动力学习的影响仍有待确定。

## Abstract
Contribution: This study has shown that a shared prompt-refinement procedure, guided by distinct affective and cognitive feedback signals, can improve held-out reference agreement and multi-label classification while reducing affective-generation variability without executor parameter updates. Background: Industry 4.0 has increased demand for personalized technical education across interconnected computing and engineering domains, while prompt sensitivity and generation variability have complicated dependable interpretation of instructional dialogue and learning outcomes. Research Questions: The study has examined whether task-specific feedback can improve affective-reference agreement, generation consistency, and cognitive classification without updating executor parameters. Methodology: A secondary language model has revised executor prompts using executor-output discrepancies against model-generated affective references for four dialogues and annotated Bloom labels for 70 learning outcomes; separate sets of 100 EduTalk conversations and 1,000 outcomes have supported held-out comparisons. Small refinement sets, unvalidated affective references, and absent learner-outcome measures have constrained interpretation. Findings: Affective mean absolute error has decreased from 0.742 to 0.702 and mean generation standard deviation from 0.307 to 0.238, while Bloom micro-F1 has increased from 0.687 to 0.893 and exact-match subset accuracy from 0.418 to 0.636. These findings have supported prompt refinement as a candidate approach for developing adaptive technical instruction, while its effects on workforce learning remain to be established.

## 2. 方法论

### 2.1 核心思想
- 采用**双模型闭环**：固定的**执行器** $f(P_t, x;\omega)$ 按当前提示作答；一个**次级"精炼器"LLM** $g$ 依据任务特定反馈 $I_t$ 改写提示：$P_{t+1} = g(I_t, P_t)$。
- **执行器参数全程冻结**，只优化自然语言指令，属于"无梯度、黑盒式提示优化"路线（与 APE / OPRO / Self-Refine 同族）。
- 两个任务**共享同一套精炼流程**，但反馈信号截然不同（情感用连续轨迹误差，认知用离散标签错误）。

### 2.2 任务一：情感轨迹估计
- 输入对话 $c=(u_1,\dots,u_n)$，执行器对每条话语打情感分 $s_i\in[0,5]$（越低越正面，2.5 为中性）。
- 为便于轨迹分析，线性映射到 $[-1,1]$：$z_i = 1 - 2(s_i/5)$。
- **参考轨迹** $y_{\text{ref}}$ 由确定性 LLM（Nemotron，temperature=0）生成，可复现但非人工标注真值。
- **反馈构造**：对每条对话独立采样 $K$ 次生成，取均值
  $$\bar y_t = K^{-1}\sum_{k=1}^{K} f(P_t, c;\omega_k)$$
  反馈 $I^{\text{aff}}_t = (c,\ \bar y_t,\ y_{\text{ref}})$，即"对话 + 平均预测轨迹 + 参考轨迹"。
- **选择准则**：在精炼集上计算 MAE，保留观测到的最优提示 $P^*$。

### 2.3 任务二：布鲁姆多标签分类
- 每个学习目标 $x$ 对应六维二值标签 $y\in\{0,1\}^6$（六个认知层级是否存在）。
- **反馈构造**：仅收集预测与标签不一致的样本
  $$E_t = \{(x_i,\ \hat y_{i,t},\ y_i) : \hat y_{i,t} \neq y_i\}$$
  精炼器据此澄清分类判据与输出格式要求（JSON 数组，含 id 与 labels 字段）。
- **选择准则**：以精炼集 micro-F1 为准保留最优提示。

### 2.4 精炼器元提示（Meta-prompt）要点
- 明确要求"修改要**可泛化**，不得对给定样例过拟合"。
- 严格约束输出格式：只输出修订后的系统提示，无解释、无前言；保留原 JSON 结构。
- 允许对提示内容进行重构、增删。

### 2.5 架构定位
- 论文给出一个概念性自适应学习架构（内容准备 → 课程知识检索 → 学习者状态表征 → 上下文响应生成 → 任务评估 → 提示精炼回路），并给出检索增强辅导算法（Algorithm 1）。
- 但**实验只评估虚线框内的"模型级提示精炼回路"**，检索、平台部署、数字孪生等均未实际执行。

## 6. 主要结论与发现

### 6.1 情感轨迹任务（100 段留出对话）
- MAE：**0.742 → 0.702**（相对降低 5.39%）。
- 平均生成标准差 σ：**0.307 → 0.238**（相对降低 22.48%）。
- 解读：与确定性参考**更接近**、输出**更稳定**；但**不等于**情感识别更准确，也不等于能可靠捕捉情绪转折点。

### 6.2 布鲁姆分类任务（1,000 条留出学习目标）
- Micro-F1：**0.687 → 0.893**（绝对 +0.206，相对 +30.00%）。
- 子集精确匹配：**0.418 → 0.636**（绝对 +0.218，相对 +52.15%）。
- 解读：多标签性能显著提升，但未识别是哪些层级或哪类错误带来改进。

### 6.3 总体结论
- 反馈驱动的提示精炼可**在不更新执行器参数**的前提下，在两个互补的教育分析任务上取得留出集端点改进。
- 这些改进**仅限模型行为层面**：既未证明情感参考具备人类效度，也未证明优化收敛，更未证明能改善学习者的学习、保持或学业成就。
- 提示精炼被定位为**自适应技术教育的候选方法**，与课程知识检索（RAG-PRISM）等路线互补而非替代。

## 7. 优点

- **问题设定有价值**：把"情感轨迹估计"与"认知层级分类"两类异质教育任务纳入**同一套提示精炼框架**，用不同反馈信号驱动，体现了对自适应教学"情感 + 认知"双维度的系统性思考。
- **方法轻量、无需训练**：完全冻结执行器参数，仅靠自然语言反馈改写提示，工程门槛低、可迁移性强，适合快速适配不同课程与任务。
- **反馈设计有针对性**：情感任务用"均值轨迹 vs 确定性参考"的连续误差；认知任务只喂"预测与标签不一致"的困难样本，属于有针对性的难例驱动，而非盲目全量反馈。
- **评估纪律较严谨**：精炼集与留出集严格隔离；明确区分"与参考一致"与"情感效度"、"输出稳定"与"不确定性降低"，避免过度解读。
- **自我批判充分**：论文用大量篇幅主动声明局限（参考非人工真值、无学习者结果、无收敛证据、无成本核算、复现信息缺失），学术诚实度较高。
- **架构视野完整**：虽只做模型级实验，但给出了与检索增强辅导、数字孪生、沉浸式教学衔接的概念架构，为后续集成研究留出接口。

## 8. 不足与局限

### 8.1 效度与测量层面
- **情感参考非真值**：$y_{\text{ref}}$ 由确定性 LLM 生成，MAE 下降只说明"更像另一个模型"，不能推断为"更懂学生情绪"。论文自己也承认需要人类评分者与评分者间一致性检验。
- **生成标准差的双重含义**：σ 下降既可能是"更稳定"，也可能是"模型收敛到某个系统性偏差"，无法区分模型随机性与真实解释歧义。
- **无学习者结果**：完全未测量参与度、坚持度、保持率、迁移或公平性，因而无法支撑任何教学决策层面的主张。

- **无强基线对比**：未与专家撰写提示、APE/OPRO/Self-Refine、或参数微调比较，"相对优越性"完全未建立。
- **无逐层级/逐错误类型分析**：Bloom 提升 0.206 的来源不可解释。
