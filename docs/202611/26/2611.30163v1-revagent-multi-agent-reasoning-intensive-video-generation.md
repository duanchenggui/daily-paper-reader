## 摘要
为推理密集型主题生成教学视频的一个核心挑战在于，展示每一步状态如何变化以及为何变化。即使动画成功渲染，所描绘的物体关系与状态转移也可能与解释相冲突，使推理过程难以理解。我们提出 ReVAgent，一个多智能体框架，它求解问题、为其解释生成关键帧，并合成教学视频。各智能体共享求解程序的执行记录，复用场景中的中间结果与构造，并检查渲染后的关键帧，以指导对解或场景的修订。我们还引入一个多维评分标准，用于评估生成的视频是否清晰呈现问题、连贯组织步骤，并利用视觉元素解释推理。我们使用人工评分校准一个多模态评判器，并将其应用于数学和算法教学视频。在评估样本中，ReVAgent 连贯地呈现多步推理，并使用图示展示关键操作如何导向后续状态。

## Abstract
A central challenge in generating instructional videos for reasoning-intensive topics is to show how and why the state changes at each step. Even when an animation renders successfully, the depicted object relationships and state transitions can conflict with the explanation, making the reasoning difficult to follow. We present ReVAgent, a multi-agent framework that solves a problem, generates keyframes for its explanation, and synthesizes an instructional video. The agents share the execution record of a solution program, reuse intermediate results and constructions in the scenes, and check rendered keyframes to guide revisions to the solution or the scenes. We also introduce a multidimensional rubric for assessing whether generated videos present the problem clearly, organize the steps coherently, and use visuals to explain the reasoning. We calibrate a multimodal judge using human ratings and apply it to instructional videos for mathematics and algorithms. In the evaluated samples, ReVAgent presents multi-step reasoning coherently and uses diagrams to show how key operations lead to subsequent states.

## 1. 核心问题与研究动机

- **背景**：视频生成模型已能合成较连贯的短片，但在**推理密集型教学场景**（数学、算法）中，视频不仅要"渲染成功"，还必须让每一步的**符号、数量、对象关系与状态转移**和解题步骤严格一致。
- **核心问题**：现有两条技术路线都存在根本缺陷：
  - **像素级视频生成模型**（Sora 类、Wan、Seedance 等）：即使给定首尾参考帧，中间帧仍会**丢失数学符号、扭曲几何对象**，视觉与解题步骤脱节（图 1(a)）。
  - **代码驱动智能体**（Manim / Code2Video / TheoremExplainAgent 等）：脚本能跑通，但**渲染出的对象关系仍可能与解释冲突**（如图 1(b) 中两个梯形声称拼成平行四边形却留有缝隙），因为解题关系需要在动画代码中被"重新实现"，多了一层易错的翻译。
- **整体含义**：作者主张把"求解—视觉规划—渲染—校验"打通为一个闭环，让**推理证据直接驱动视觉构造**，从而使教学视频的逻辑连贯性可被显式控制与验证。

## 2. 方法论

### 2.1 核心思想
三阶段流水线 + 共享执行记录 + 关键帧回检：

$$q \xrightarrow{A_{solve}} T \xrightarrow{A_{visual}, R_{image}} (S, I) \xrightarrow{M, Encode} \tilde{V}$$

### 2.2 关键技术细节

- **① 可执行逻辑推理（Solver Agent）**
  - 求解智能体选择策略并写出程序 $P = A_{solve}(q)$，执行得到**解记录** $T=(y,\tau,W)$：答案 $y$、轨迹 $\tau$（步骤编号、解释、中间计算状态）、证据 $W$（计算校验与几何构造的坐标/图元参数）。
  - 关键点：$W$ 中的构造可被下游**直接复用**，无需在动画代码中重算。

- **② 推理接地的视觉规划（Visual Agent）**
  - 输出有序场景序列 $S=(s_1,\dots,s_K)$，每场景 $s_k=(b_k,e_k,\phi_k,O_k,H_k)$：$b_k$ 绑定 $\tau$ 中的步骤、$e_k/\phi_k$ 为讲解文本与公式、$O_k$ 可见对象、$H_k$ 高亮对象。
  - 对象集合 $O_k = O_k^{exec} \cup O_k^{gen}$，其中 $O_k^{exec}\subseteq O(W)$ 按**原始坐标与几何参数拷贝**，从机制上避免符号遗漏与形变。
  - 固定渲染器生成关键帧 $I_k=R_{image}(e_k,\phi_k,O_k,H_k)$。

- **③ 受控场景到视频渲染**
  - 自定义渲染器统一绘制图形、文字、公式并高亮指定对象；按归一化时间 $u_n\in[0,1]$ 施加预定义运动规则 $\mathcal{M}$：
    $F_{k,n}=R_{image}(e_k,\phi_k,\{\mathcal{M}(o,u_n):o\in O_k\},H_k)$，逐场景停留供阅读，拼接 $C_k$ 后编码为 MP4。

- **④ 验证与迭代修订（Verifier）**
  - 输出三元二值检查 $(c_m,c_g,c_t,\mathcal{E})$：数学正确性、图形是否对应推理步骤、文字可读性；缺陷位置记入 $\mathcal{E}$。
  - 接受条件：$a=\mathbb{1}[c_m=c_g=c_t=1 \wedge \mathcal{E}=\varnothing]$。
  - 路由策略：$c_m=0$ 回送**求解智能体**（重生成 $T$ 及全部依赖产物），否则回送**视觉智能体**（保留 $T$）；最多 $R=3$ 轮修订，超预算则返回最满足评审标准的候选并附带评审状态。

## 7. 主要贡献与亮点

1. **问题定位准确**：把"教学视频的逻辑一致性"从模糊的"质量"中剥离出来，定义为符号/数量/对象关系/状态转移与解题步骤的可核验一致，并用图 1 的失败案例（梯形拼合留缝）给出直观反例。
2. **架构上做了正确的"去翻译"**：让 Solver 产出的坐标与图元参数 $W$ 被 Visual Agent 以 $O_k^{exec}$ 形式**原样拷贝**，从机制上消除"解题关系在动画代码中被重新实现"这一误差来源，而不是靠提示词或后处理去补救。
3. **闭环可控**：Verifier 的三元检查 + 按失败类型路由（数学错→回 Solver，视觉错→回 Visual）比"整体重生成"更经济，也使错误归因可解释；$R=3$ 的预算设定务实。
4. **验证层次较完整**：自动指标（IQ/AQ/MS/CLIP-T）+ LLM 评委六维 + 45 名学生 1,577 条人类评分 + 定性同帧对比 + 效率对比 + 4 组消融 + 对齐控制实验，形成了"结果—机制—成本"三层证据。
5. **工程可复现性较好**：渲染器为自定义确定性渲染，关键帧与视频帧由同一 $R_{image}$ 生成，避免了"关键帧好看、成片崩坏"的常见落差。

- **过程性统计缺失**：未报告修订轮次分布、首次通过率、各阶段失败类型占比、超预算回退比例。这些数据对判断"闭环是否真的在起作用"至关重要，也是审稿人最可能追问的点。
- **缺少学习效果证据**：全文以"视频质量"为终点，未做学习者前后测或理解度对照实验，"教学有效性"目前只是间接推断。
- **与相关工作的直接对比不足**：LASEV、ALGOGEN、SGA、TheoremExplainAgent 等仅作文字讨论，缺少同任务数值对比，削弱了"优于现有推理密集型视频方案"的说服力。
- **可扩展性未讨论**：当前渲染器为自定义实现，对象类型与运动规则 $\mathcal{M}$ 是预定义的，对开放域（如物理仿真、化学结构、生物过程）的泛化能力、以及新增图元所需的人工成本均未评估。

## 9. 启示与可复用要点

- **"证据复用"优于"证据重述"**：任何"推理→可视化"系统都应尽量让下游直接消费上游的**结构化中间产物**（坐标、参数、约束），而非让下游模型重新表述。这一原则可迁移到图表生成、UI 生成、仿真动画等场景。
- **按错误类型路由的验证器**比单一打分器更有工程价值：它把"哪里错了"转化为"回哪一环修"，显著降低重试成本。
- **关键帧–视频同源渲染**是避免"首尾帧好看、中间帧崩坏"的实用手段，值得在像素级视频生成与代码驱动之间作为一种混合范式继续探索。
- **人类校准 LLM 评委**的流程（按问题族划分校准/开发/测试集，避免族泄漏）设计规范，但其低相关性提醒：校准 prompt 只能部分弥补评委偏差，不能替代人类主表。

## 10. 总体评价

ReVAgent 的贡献主要在于**架构层面的因果性设计**而非单纯刷分：它准确识别出"代码驱动方案仍需二次翻译"这一被忽视的失败源，并用"解记录复用 + 关键帧回检 + 类型化路由"给出可执行的工程解法，配套的对齐控制实验（20/20 vs 15/20、token −65.3%）是全文最有说服力的机制证据。在 100 任务、9 类基线、双骨干的规模下，其教学六维与 AQ 的领先幅度具有实质意义。

主要短板在**评测效度与统计严谨性**：核心结论高度依赖单一 LLM 评委（与人类校准相关性偏低），关键消融规模偏小且无显著性检验，缺少学习效果与过程性统计，与同期推理密集型视频工作的直接数值对比亦不充分。若能在人类主表、教学专用指标、失败归因统计与开放域泛化四个方面补强，本文的说服力将从"设计合理、结果亮眼"提升到"机制确证、可被独立复现与推广"。

**一句话概括**：以"解记录直接驱动视觉构造"取代"让模型重写动画代码"，配合关键帧回检与按错因路由的迭代修订，ReVAgent 在推理密集型教学视频上实现了逻辑一致性与生成效率的双重改善，但其教学有效性证据仍以模型评委为主，尚待人类主表与学习效果实验补全。
