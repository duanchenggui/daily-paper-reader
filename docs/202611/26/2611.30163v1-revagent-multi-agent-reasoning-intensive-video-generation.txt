## Abstract 

A central challenge in generating instructional videos for reasoning-intensive topics is to show how and why the state changes at each step. Even when an animation renders suc-cessfully, the depicted object relationships and state transi-tions can conflict with the explanation, making the reason-ing difficult to follow. We present ReVAgent, a multi-agent framework that solves a problem, generates keyframes for its explanation, and synthesizes an instructional video. The agents share the execution record of a solution program, reuse intermediate results and constructions in the scenes, and check rendered keyframes to guide revisions to the so-lution or the scenes. We also introduce a multidimensional rubric for assessing whether generated videos present the problem clearly, organize the steps coherently, and use vi-suals to explain the reasoning. We calibrate a multimodal judge using human ratings and apply it to instructional videos for mathematics and algorithms. In the evaluated samples, ReVAgent presents multi-step reasoning coher-ently and uses diagrams to show how key operations lead to subsequent states. 

## 1. Introduction 

Video generation has advanced rapidly in recent years, yet generating reasoning-intensive videos remains challeng-ing. For example, generating logically coherent educational videos for mathematics and algorithms requires turning so-lution steps and their rationale into visual explanations that help learners understand how a solution is reached step by step. Let’s consider Kruskal’s minimum spanning tree al-gorithm. At each step, the video should preserve the input graph and edge weights, distinguish accepted edges, and show a new edge being accepted only if it joins two different components. Such logical coherence requires each scene’s quantities, symbols, and object relations to match the cor-

responding solution step, and changes between scenes to reflect the computations, constructions, or algorithmic op-erations being explained. On one hand, general-purpose video generation mod-els [1, 2] can synthesize coherent videos from text or ref-erence images. In videos that teach mathematics or algo-rithms, however, numbers, operators, and geometric rela-tions carry information about the solution, so an error in a single visual element can change the meaning of the expla-nation. As Fig. 1(a) illustrates, even with reference images for the first and last frames, video generation models [3] can omit mathematical symbols or deform objects in intermedi-ate frames. Such errors can cause the visuals to diverge from the corresponding solution steps, making it difficult for these models to reliably depict multi-step reasoning in instructional videos. On the other hand, code-driven approaches offer a promising way to keep symbols and graphics accurate throughout a solution while providing explicit control over what is shown and how it changes. These approaches pro-vide this control through programmatic rendering [4], using animation tools such as Manim [5] to draw formulas and graphics from explicit specifications. Advances in large lan-guage models (LLMs) enable agents in Code2Video [6] and TheoremExplainAgent [7] to plan explanations and write executable animation scripts [8]. Even when scripts run successfully, rendered object relations may conflict with a solution step [7, 9]. In Fig. 1(b), two trapezoids described as forming a parallelogram still leave a gap where they should meet. Even with a correct solution, agents must reimple-ment its object relations and state changes in animation code. This additional translation makes visual control de-pendent on code implementation, limiting how fully agents can use their reasoning to organize and adapt visual expla-nations. ## 2. Related Work 

General-purpose video generation. Large-scale video generation models have extended synthesis to longer clips and multi-shot sequences [10–12], with text or reference images guiding the output [13, 14]. Sora [15] demonstrates generation across a range of durations, resolutions, and as-pect ratios, and Seedance 1.0 [1] supports multi-shot gen-eration from text or images. Open-weight models such as Wan [2] and CogVideoX [16] provide publicly available im-plementations for comparative study [17, 18]. Mathemati-cal and algorithmic instruction also requires that formulas, relations between depicted objects, and state changes across scenes agree with the corresponding solution steps. Code-driven educational video generation. Animation libraries such as Manim [5] let authors write scripts that specify the layout, transformations, and timing of formu-las and graphics. As large language models (LLMs) gained the ability to write these scripts from instructional content, agent-based systems began to divide the work into plan-ning, code generation, and revision after rendering. Theore-mExplainAgent [7] plans theorem explanations and imple-ments them as Manim animations. Code2Video [6] turns lecture content into storyboards and uses visual feedback to refine the rendered layout. VisualEDU [19] uses code and visual feedback to generate step-by-step explanations of mathematical problems. LASEV [20] coordinates so-lution, illustration, and narration agents, with the illustra-tion agent generating code from a reviewed textual solu-tion. For algorithm visualization, ALGOGEN [21] renders execution traces emitted by generated trackers. SGA [9] extracts scene graphs from animation code to detect spatial conflicts. ReVAgent links instructional scenes to executed solution steps, directly reuses selected geometric construc-tions produced by the solver, and uses the same solution evidence to review the rendered keyframes.

4.2. Human-Calibrated Instructional Evaluation 

A human-calibrated multimodal judge evaluates videos from the learner’s perspective across six dimensions on a five-point scale. Legibility and problem clarity assess readable visual information and clear problem conditions and goals; visual helpfulness and self-reported understand-ing reflect how graphics support comprehension and view-ers’ subjective understanding. Step coherence and reason-ing clarity assess how solution steps connect and why key steps are taken, emphasizing clear, coherent presentation of the solution process and its rationale in reasoning-intensive videos. Human and judge scores are reported on a 100-point scale ( ×20 ). The human evaluation set comprises 60 generated videos and ten online teaching videos, with 1,577 valid video-level rating records collected from 45 raters. All 45 raters were students taking a data structures and algorithms course. For video v and dimension d, we use the mean opinion score across raters [24] as the human evaluation target:

## 5. Experiments 

We evaluate ReVAgent on mathematical and algorithmic in-structional video generation tasks. Combining video qual-ity and semantic evaluation with human-calibrated instruc-tional evaluation, we compare the instructional quality, vi-sual quality, and semantic relevance of videos generated by different methods. We also use qualitative examples to an-alyze reasoning steps and visual explanations, and ablation studies to examine the roles of the solver, visual, and verifi-cation agents. 

5.1. Experimental Setup 

The planned comparison uses a shared set of 100 tasks, in-cluding 50 mathematical and 50 algorithmic tasks. We com-pare ReVAgent with four video generation models, Wan2.1-T2V 1.3B, Wan2.2-T2V 27B [26], MiniMax H3-33B, and LTX-2.5 22B [25], as well as Direct Manim, Code2Video, VisualEDU, and ManimAgent. Code-based methods and ReVAgent use Qwen3.8-27B and Qwen3.5-4B backbones. On shared tasks, methods receive the same problems, input data, and instructional requirements. The four text-to-video models use the same fixed 100 English-language tasks. All methods are evaluated with the same automatic metrics and frozen human-calibrated judge. 

5.2. Video Quality and Semantic Comparison 

Among the video samples reported in Table 2, the 27B ReVAgent configuration shows its largest lead over the baselines in aesthetic quality (AQ), scoring 0.578 and ex-ceeding the strongest baseline, MiniMax H3-33B, by 0.181. ReVAgent also ranks first in task-related semantic relevance (CLIP-T), edging out Direct Manim, the strongest code-based baseline on this metric, by 0.002. Both methods use code to explicitly specify and render formulas, diagrams, and labels. This can help preserve task-specific content that direct pixel generation may distort or omit. The pixel-based baselines in the table obtain lower CLIP-T scores. 6Wan2.1 and Wan2.2 achieve the two highest imag-ing quality (IQ) scores, illustrating the advantage pixel-based generators can have in low-level frame quality. ReVAgent remains close to both, trailing them by only 0.022 and 0.009, respectively. On motion smoothness (MS), ReVAgent trails the best-scoring method, Code2Video, by only 0.0014. Section 5.3 further examines formula legi-bility, the coherence of reasoning steps, and how well di-agrams support the explanation. 

5.3. Human-Calibrated Instructional Comparison 

Table 3 shows that the 27B ReVAgent configuration achieves the highest scores across all six evaluation dimen-sions in the reported video subsets, with a six-dimensional average of 91.52. Its step coherence, reasoning clarity, and visual helpfulness scores reach 92.12, 88.40, and 90.10, ex-ceeding Code2Video by 5.56, 5.92, and 5.86 points, respec-tively. These results indicate favorable organization of rea-soning steps, presentation of supporting explanations, and correspondence between diagrams and instructional content within the evaluated samples. Wan2.1 and Wan2.2 have the two highest reported IQ values and six-dimensional judge means of 22.30 and 37.98, respectively. MiniMax H3-33B and LTX-2.5 22B obtain six-dimensional means of 49.83 and 31.69, respectively, both well below ReVAgent’s 91.52. Although some code-based baselines score close to ReVAgent on legibility and problem clarity, their rendered outputs still differ in how they position labels relative to di-agrams and organize content on screen. The next section uses a common Heron’s formula task to examine how these differences affect the reader’s ability to follow the deriva-tion. 

5.4. Visualization Analysis 

Figure 4 compares nine methods on the same Heron’s for-mula task at 95% video progress. The pixel-based text-to-video models exhibit errors in mathematical notation and geometry. Wan2.1 and Wan2.2 obtain the two highest imag-ing quality (IQ) scores, yet some text and numbers in the Wan2.1 frame are difficult to read, and Wan2.2 misspells the semiperimeter label and depicts a curved outline in place of the triangle. MiniMax H3-33B renders unrelated coordinate curves with malformed labels. LTX-2.5 22B shows two cir-cular outlines and an incomplete list of side lengths. These errors make it difficult to connect the visuals to the problem statement and the calculation steps. The code-based baselines show the correct area, but some labels and layouts make the frames harder to read. Code2Video places the side lengths near the vertices, leav-ing viewers to infer which length belongs to each edge. Di-rect Manim has overlapping titles, while VisualEDU places some labels away from the corresponding diagram ele-ments, displays low-contrast formulas, and clips content at the bottom of the frame. For beginners, these issues make it harder to interpret the labels and follow the derivation, reducing the videos’ suitability as standalone teaching ma-terial for a wider audience. ReVAgent presents the explanation and diagram in sep-arate areas of the frame and retains the original triangle, all three side labels, the semiperimeter, and the area in the final view. The differences in layout, contrast, and label placement are consistent with the aesthetic quality (AQ) re-sults in Sec. 5.2, where ReVAgent scores 0.578 and the best code-based baseline scores 0.367. 

5.5. Generation Efficiency 

We measure generation efficiency as generation time per minute of output video, computed by dividing total genera-tion time by total actual playback duration. Timing covers inference, rendering or encoding, and the method’s own re-visions. ReVAgent takes 5.42 minutes per minute of video, compared with 19.92 minutes for Direct Manim, or about 27% of its time. VisualEDU and ManimAgent take 92.56 and 48.18 minutes, respectively. ReVAgent has a lower gen-eration time per minute of video than all four Manim base-lines (Figure 5(b)). Our method reuses a fixed renderer and organizes execution results into structured scenes, avoiding the need to generate and debug a complete animation pro-gram for each problem. LTX-2.5 22B takes 5.32 minutes per minute of video, while its six instructional quality scores range from 25.98 to 38.32, with low step coherence and rea-soning clarity. The qualitative analysis and quality evaluation show that longer generation time does not necessarily lead to better instructional presentation. Wan2.2 and MiniMax H3-33B take longer to generate videos than ReVAgent, yet their videos still exhibit errors in mathematical notation and di-agrams that deviate from the problem. LTX-2.5 22B is slightly faster, but its low step coherence and reasoning clar-ity indicate that fast visual generation alone is insufficient for a clear instructional explanation. ReVAgent achieves higher instructional quality scores while maintaining a low generation cost, providing a better balance between genera-tion efficiency and instructional quality.

Conclusion 

We introduced ReVAgent, a multi-agent framework for generating instructional videos for mathematics and algo-rithms. ReVAgent uses a shared program execution record to build instructional scenes and verify rendered keyframes, linking formulas, diagrams, and state changes to specific solution steps. We also developed a six-dimensional rubric for instructional quality and used human ratings to cali-brate a multimodal judge. On the evaluated video samples, ReVAgent achieved the highest aesthetic quality score and ranked first among the compared generation methods on all six dimensions assessed by the judge, including step coher-ence, reasoning clarity, and visual helpfulness. Executable reasoning thus supports coherent visual explanations. 

## LLM Usage Statement 

In our experiments, ReVAgent uses the models identified as Qwen3.8-27B and Qwen3.5-4B for problem solving, scene planning, and keyframe verification. The code-generation baselines are evaluated with the same backbones, while the video generation baselines use their respective pretrained models. For human-calibrated instructional evaluation, we calibrate a prompt for the frozen Qwen3.8-27B judge using human ratings, then apply the fixed prompt to score videos on six dimensions of instructional quality.
