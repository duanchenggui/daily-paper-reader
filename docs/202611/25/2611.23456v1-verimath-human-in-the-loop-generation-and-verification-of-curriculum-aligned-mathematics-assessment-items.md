## 摘要
数学评估题目的自动生成是教育人工智能中一个不断发展的领域，但课堂部署仍具挑战性。生成的题目必须满足多重约束：数学正确性、课程对齐、适当的认知难度以及教育者可审查性。尽管已有工作在文本生成方面取得了进展，可靠的评估命题仍需对本地化考试格式进行细粒度控制，并依赖专家教育判断。为应对这一挑战，我们提出 VeriMath，一个通用的、人在回路中的框架，用于生成严谨且受课程约束的数学评估草稿。该框架利用带标注的参考题目，将生成锚定到所要求的考试部分和认知推理层级，然后在提交草稿供专家审查之前，依次执行自动验证和引导式修复。我们通过一个国家课程案例研究评估 VeriMath，使用越南 12 年级课程的 4,555 道数学题目，以及涵盖多项选择、判断题和简答题格式的 50 个不同生成需求。在两个模型骨干上，该框架每次运行可为 94%（47/50）的需求生成验证器接受的草稿。盲审专家评估确认了较高的数学准确性和课程对齐度，而严格的教师可用性评估最多接受 56.8% 的生成题目。对未通过草稿的分析揭示了持续存在的领域无关挑战，涉及格式、陈述有效性和解题步骤完整性。这些发现表明，VeriMath 能够在严格约束的国家课程框架内生成高度可审查的评估草稿，从而连接生成式 AI 与可靠的教育应用。

## Abstract
Automatic generation of mathematics assessment items is a growing area in educational artificial intelligence, yet classroom deployment remains challenging. Generated questions must satisfy multiple constraints: mathematical correctness, curriculum alignment, appropriate cognitive difficulty, and educator reviewability. While prior work has advanced text generation, reliable assessment authoring requires granular control over localized examination formats and expert educational judgment. To address this challenge, we present VeriMath, a generalized, human-in-the-loop framework for generating rigorous, curriculum-constrained mathematics assessment drafts. Using annotated reference items, the framework anchors generation to the requested examination section and cognitive reasoning level, then applies sequential automated verification and guided repair before submitting drafts for expert review. We evaluate VeriMath through a national curriculum case study using 4,555 mathematics items from the Vietnamese Grade 12 curriculum and 50 distinct generation requirements covering multiple-choice, true/false, and short-answer formats. Across two model backbones, the framework produces verifier-accepted drafts for 94% (47/50) of requirements per run. Blind expert evaluations confirm high mathematical accuracy and curriculum alignment, with strict teacher-readiness assessments accepting up to 56.8% of generated items. Analysis of rejected drafts reveals persistent domain-agnostic challenges involving formatting, statement validity, and solution-step completeness. These findings demonstrate that VeriMath can bridge generative AI and dependable educational applications by producing highly reviewable assessment drafts within tightly constrained national curriculum frameworks.

## 1. 核心问题与研究背景

- **研究动机**：数学测评题是课堂练习、形成性反馈与备考的核心载体，其质量取决于学习目标、认知要求、作答格式与评分解释之间的一致性（Anderson 等；Haladyna 等），而不仅是语言通顺。数学题还要求题干、表征、解法与答案格式对目标学生保持数学上的自洽。
- **核心问题**：**课程约束下的数学测评题命题（curriculum-constrained item authoring）**。给定年级、课程学习成果、测评 schema、作答约束与认知/难度规格，要求生成一份原创题目草稿，含正确解答与可用元数据，且须满足：数学有效、对齐学习成果、匹配要求层级、结构符合目标题型、LaTeX 可编译、相对历史题库足够新颖。
- **现有方法的局限**：
  - 模板/符号化生成（如 Polozov 等）可控性强，但语言与数学多样性有限，难以适配本地考试格式；
  - 神经词问题生成（Zhou & Huang；Z. Wang 等）提升流畅度与多样性，但可能出现隐藏假设、官方答案错误、表述歧义、课程错配或近似抄袭；
  - LLM 教育生成研究（MATHWELL、EDUMATH、Cassano 等）表明"可解 + 答案正确"不等于教学适切与标准对齐；
  - 合成数学数据管线（MetaMath、WizardMath、MathGenie、OpenMathInstruct 2 等）主要以下游求解性能为评价目标，而非教师课堂可用性。
- **三个研究问题**：RQ1 能否在显式课程/格式/层级约束下生成结构完整的测评草稿；RQ2 教师标注语料能否作为难度与风格锚点而不诱导表面复用；RQ3 自动验证与教师可用性判断之间的差距有多大。
- **整体含义**：论文主张把"题目生成"重新表述为"测评命题工作流"，将生成、验证与专家判断显式连接，输出的是**待教师复核的草稿**而非正式考题。

## 2. 方法论

### 2.1 任务形式化

- 生成需求记为 \(R=(s,o,L,q,m)\)：\(s\) 为部署方定义的测评 schema，\(o\) 为课程学习成果，\(L\) 为本地化认知/难度规格，\(q\) 为作答约束（答案类型、语言），\(m\) 为课程元数据（年级、学科、章节等）。
- 输出草稿 \(X=(P,S,M)\)：\(P\) 题干、\(S\) 解答与官方答案、\(M\) 元数据。
- 关键设计：schema 集合 \(S\) 与难度分类体系 \(L\) **均不由框架固定**，而由部署上下文提供，框架本身与国别课程解耦。

### 2.2 核心思想

两阶段推理时组件：**难度锚定（Difficulty Anchoring）** + **连续验证机制（Consecutive Verification Mechanism, CVM）**，流程为：需求 → 检索锚点 → 生成 → 自我改进 → 反复验证/修复 → LaTeX 格式修复 → 提交专家复核。

### 2.3 难度锚定与候选生成

- 从参考语料 \(D_{ref}\) 中按 schema 与层级兼容规则筛出 \(k\) 个锚题 \(B_R=\{b_1,\dots,b_k\}\)。
- 单层 schema 要求层级完全一致；判断对错簇（四语句）采用**三层确定性匹配**：① 四元层级 profile 精确匹配 → ② 层级分布匹配 → ③ 目标 profile 中出现的每个层级在锚题中至少出现一次。若三层都无法凑够锚点，则**直接拒绝该需求**，不退化为仅按 schema 检索。
- 锚点仅作格式、推理深度与命题风格的正向参考，同时作为**内容复用的负向参考**；生成器按 \(s\) 对应的输出 schema 生成初始候选 \(X_0\)，随后做一次自我改进（检查数学错误、格式问题、层级错配），得到 \(X_{cand}\)。
- 生成器、验证器、修复器使用**不同角色提示词**：生成器扮演命题专家，验证器扮演严格数学教师（只判错、不代改），修复器仅在收到详细失败报告后修改。

### 2.4 连续验证与修复（CVM）

- 验证器返回 \((d_t,E_t)=M_{ver}(X_t,R)\)，\(d_t\in\{\text{pass},\text{fail}\}\)，\(E_t\) 为失败轨迹。
- 连续通过计数器更新：
  \[
  c_t=\begin{cases}c_{t-1}+1,& d_t=\text{pass}\\ 0,& d_t=\text{fail}\end{cases}
  \]
- 候选更新：
  \[
  X_{t+1}=\begin{cases}X_t,& d_t=\text{pass}\\ M_{gen}(R,B_R,E_t),& d_t=\text{fail}\end{cases}
  \]
- **接受条件**：连续 \(N=3\) 次验证通过；修复预算 \(T=3\)（最多三次验证器引导的修复），任一失败都会将计数器清零；预算耗尽则判为 rejected sample。
- 通过后再执行独立的 LaTeX 格式修复（最多 3 次尝试）。
- 设计意图：使接受结果不依赖单次"幸运"判定；把失败轨迹转化为可修复信号；任何被接受题目都可回溯到需求、锚点、验证决策与修复历史，提升可审计性。

### 2.5 新颖性与评价指标

- 新颖性：\(\text{Nov}(P)=1-\max_{b\in D_{ref}}\frac{v_P\cdot v_b}{\|v_P\|\|v_b\|}\)，其中 \(v\) 为多语种句向量。
- 明确区分**运行有效性诊断**（接受率、成本、新颖性）与**教师就绪度**（盲审评分），后者才是主要质量证据。

## 3. 实验设计

### 3.1 场景与数据

- **单一国家课程案例**：越南 12 年级数学（对应国家高中毕业考试）。
- **参考语料 \(D_{ref}\)**：4,555 道国家/模拟考试题，由数学教师两阶段标注（初标 + 资深教师裁决分歧），标注 schema 与认知/难度层级；按考试来源划分为锚点集与独立评测集以降低重叠。
- **三种测评 schema**（案例配置，非框架强制）：
  - \(s=1\) 多项选择：1 题干 + 4 选项 + 1 正确标签 + 详细解答（语料 2,988 题）；
  - \(s=2\) 判断对错簇：共享题干 + 4 个语句 + 4 个二值标签 + 全语句详解（449 题），层级为四元 profile；
  - \(s=3\) 简答：1 题干 + 1 数值答案 + 详细解答，必要时含取整说明（1,118 题）。
- **三级认知/难度**：Recognition（直接回忆，≤1 步推理）、Comprehension（需解释与概念组合）、Application（多步或非套路策略）；作者明确说明这是教师操作类别，**不是心理测量学标定的难度参数**。
- **需求集**：50 个需求，固定 schema 比例 6:2:2（30 多选、10 判断簇、10 简答）；判断簇每题含 4 个独立语句，故共对应 **80 个学习成果槽位**（32 Recognition / 24 Comprehension / 24 Application；67 个微积分统计、13 个几何）。

### 3.2 模型骨干与解码

- 两个骨干：**Qwen3-8B** 与 **gpt-oss-20b**；同一骨干内生成、自我改进、验证、修复共用同一模型，仅角色提示词不同（**验证器不是独立模型族**）。
- 生成使用 temperature 1.0 随机采样；CVM 需 3 次连续通过、最多 3 次修复；后接 LaTeX 修复 pass。

### 3.3 评价方式（Benchmark）

- 论文**没有使用公开标准 benchmark**，而是自建案例研究：同一 50 需求、同一配置在两个骨干上跑完整管线。
- 指标包括：验证器接受数/接受率、嵌入新颖性、每接受题目的验证器调用数与修复数、单题运行时（均值/中位数）、输入/输出/总 token；按 schema 分层与按管线步骤的成本拆解。
- **盲审专家评审**：评审者不知生成来源、模型身份与过程轨迹；四项准则——数学正确性与答案一致性（二值）、学习成果对齐（二值）、层级匹配（1–5）、清晰度/考试可用性（1–5）；通过标准为两项二值均通过且两项评分均 ≥4；多评取平均；并记录 9 类错误标记（错答案、无效题面、多解、解法步骤缺失/错误、学习成果错误、过易、过难、歧义/缺条件、格式或公式错误）。
- 另探索了 LLM-as-judge（四维 0–1 打分）作为独立诊断角色，但**未作为主要就绪度证据**。
- **明确声明无 baseline、无消融**（5.1.3 节），接受率不能解释为各组件因果贡献。
